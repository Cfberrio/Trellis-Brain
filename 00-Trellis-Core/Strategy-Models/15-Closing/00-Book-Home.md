# Closing — Book Home

## Parent
- [[../Hormozi-Home|Hormozi Home]]

## Purpose
Hub for the Hormozi playbook *$100M Playbook: Closing — How to Turn Nos into Sales*. Holds distilled framework notes derived from this playbook. Closing is a tactical objection-handling playbook centered on one operating thesis: **objections are not obstacles, they are blame** — a maybe-bucket prospect avoids deciding by handing decision-making power to something external (circumstances, other people, or the self), and the closer's job is to return that power so the prospect can make a genuine decision (yes or no — both acceptable outcomes).

This hub does not contain raw book content. Provenance is carried via `source_reference` frontmatter on each canonical note plus the Source Map.

## Reuse vs. New Decisions (vs. existing books)
- **Bonuses / Guarantees as risk-reversal at close** — defined in `01-100M-Offers/Hormozi-Bonuses` and `01-100M-Offers/Hormozi-Guarantees`. The Closing playbook uses guarantees as a closing lever (the Guarantee Closes sub-section). Closing links there rather than re-canonicalizing the guarantee mechanic. The closing-specific application (how guarantees get verbally framed during a close) is canonical in [[Hormozi-Closing-Self-Closes|Self-Closes]] Guarantee Closes section.
- **Value Equation behind "value too low ≠ price too high"** — defined in `01-100M-Offers/Hormozi-Value-Equation`. Closing references it inside Money close logic (translating "too expensive" into "not enough value yet"). Reused, not duplicated.
- **BAMFAM (book-meeting-from-meeting)** — defined in `10-Lead-Nurture/Hormozi-BAMFAM`. Closing is downstream of the booked call; BAMFAM still belongs to Lead-Nurture even when invoked in a closing context.
- **Cancellation-Saves objection pattern (vent-then-validate, save-with-redo, save-with-upsell)** — defined in `14-Retention/Hormozi-Cancellation-Saves`. Different operating moment (post-purchase save), but conceptually adjacent. Closing does not re-canonicalize.
- **STAR qualification** — Hormozi introduces STAR explicitly inside this playbook (Author Note p. 28) but treats it as a prerequisite filter that lives upstream of closing. Canonical mention is here in this folder; if other books later need a deeper STAR note, this folder is the home.

## Canonical Home Rule
The 7 frameworks above are canonical in this folder. They are specific to objection handling on the live sales call (qualified maybe-bucket prospects, post-ask) and not duplicated elsewhere. Bonuses / Guarantees / Value Equation principle remain canonical in `01-100M-Offers/`; this book links to them rather than duplicating. BAMFAM remains canonical in `10-Lead-Nurture/`. Cancellation-Saves remains canonical in `14-Retention/`.
