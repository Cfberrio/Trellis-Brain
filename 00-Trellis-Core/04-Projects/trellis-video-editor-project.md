# Trellis-Video-Editor-Project

## Canonical Statement

- **decision**: The 'Trellis Video Editor' project aims to evolve the After Effects editing workflow to produce varied styles by analyzing reference videos (rhythm, cuts, transitions, text, audio sync) and converting them into actionable instructions for new content, rather than relying on static templates.
- **fact**: Success criteria for the project is defined as the ability to produce three materially different video edits from the same source material using three different reference styles, with each result being measurably closer to its reference style than the others.
