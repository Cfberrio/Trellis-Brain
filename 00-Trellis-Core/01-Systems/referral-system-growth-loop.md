# Referral-System-Growth-Loop

## Canonical Statement

- **process**: Trellis referral systems should be designed as self-feeding loops where members invite others based on visible progress, time savings, or status, rather than aggressive affiliate tactics.
- **rule**: Referral incentives should be product-aligned (e.g., sprint access, template packs, upgrades) to reinforce system usage rather than distracting from it.
- **fact**: Publicly showcasing member wins within the community and on social media acts as a primary driver for referral curiosity.
