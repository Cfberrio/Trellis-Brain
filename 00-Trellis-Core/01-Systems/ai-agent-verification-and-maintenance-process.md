# AI-Agent-Verification-and-Maintenance-Process

## Canonical Statement

- **process**: To build trust in AI agents, implement a 'verification skill' that allows the agent to programmatically run code, take traces, and verify outputs against real application environments.
- **process**: Use a 'feature map' to provide agents with context on how to navigate UI features, DOM elements, and keyboard shortcuts, enabling them to handle vague user reports effectively.
- **process**: Maintain agent skills using 'evals' (unit tests for agents) that run in isolated environments to verify performance and prevent regression as the codebase evolves.
