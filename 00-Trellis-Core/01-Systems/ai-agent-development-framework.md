# AI-Agent-Development-Framework

## Canonical Statement

- **process**: AI agent development follows a trust-based progression: from human-in-the-loop verification to autonomous cloud agents. Verification skills (programmatic app interaction) and feature maps (spatial awareness) are mandatory prerequisites for scaling agent autonomy.
- **rule**: Verification skills must be built locally first to allow human observation of agent interactions before scaling to cloud-based autonomous agents.
- **rule**: Codebase architecture is the highest-leverage constraint for agent performance; enforcing atomic PRs, import boundaries, and linting rules ensures the shortest path is the best path for agents.
