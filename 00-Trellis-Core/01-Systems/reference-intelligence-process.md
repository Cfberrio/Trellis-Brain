# Reference-Intelligence-Process

## Canonical Statement

- **process**: Reference Intelligence is a structured process for extracting mechanisms (pacing, animation, structure, etc.) from reference videos to apply to new content, rather than copying content literally. It follows a flow of: Analyze -> Extract Mechanism -> KEEP/ADAPT/REJECT/UNKNOWN -> Apply to Target.
- **rule**: Reference videos must be stored within the specific job folder, not in global brand folders like STYLE_EVIDENCE or CORE.
