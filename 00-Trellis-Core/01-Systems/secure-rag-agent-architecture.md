# Secure-RAG-Agent-Architecture

## Canonical Statement

- **fact**: A secure RAG-based AI agent architecture requires three layers: permission-aware retrieval (ACLs applied before search), a 'cite-or-refuse' response policy, and a secure execution environment (e.g., OpenShell/MicroVM) with a gateway guard to prevent unauthorized actions or data leaks.
