# Claude Capabilities Taxonomy

## Canonical Statement

- **definition**: A Skill is a set of instructions or commands (e.g., /meta, /dr) that changes how Claude thinks or responds without connecting to external tools.
- **definition**: An MCP (Model Context Protocol) or Connection is a real link that allows Claude to interact with external tools (e.g., Notion, GHL, Obsidian, ClickUp) to read, write, or execute actions.
- **definition**: A Workflow is a process that combines multiple skills, connections, and steps to complete a complex task (e.g., Website Motion Graphics, SMS Draft Agent).
- **rule**: Claude-related documents should be organized into three main categories: Skills (instructional), MCP/Connections (tool-based), and Workflows (process-based).
