# GHL - Configuring Multi-User Call Forwarding

## Canonical Statement

- **fact**: By default, a GHL number only rings the configured user/route; other team members will not receive calls on the mobile app unless multi-member forwarding is enabled.
- **process**: To enable staff to receive calls on the GHL mobile app: Go to Settings > Phone Numbers > Edit Configuration > Call Forwarding, then activate 'Ring More Team Members' and select the relevant staff.
