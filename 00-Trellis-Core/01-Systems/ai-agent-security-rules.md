# AI-Agent-Security-Rules

## Canonical Statement

- **rule**: AI agents interacting with private documents must follow three core security rules: 1) Apply ACL permissions before searching (only search what the user can see); 2) Cite sources or refuse to answer if information is missing (never invent); 3) Security logic (permissions, secrets, deletion guards) must reside outside the agent's control.
