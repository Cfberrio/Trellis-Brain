# Easy Sign Express - User Guide

## Canonical Statement

- **process**: To use Easy Sign Express, users log in via Google at easy-sign-express.lovable.app and complete a one-time onboarding as an Individual or Company to define the visible sender.
- **process**: Creating a new signature request involves a 5-step assistant: upload PDF, set title, add signers (name/email), drag fields (signature, initials, date, text, checkbox) assigned to signers, and review/save draft.
- **fact**: Document status follows a specific timeline: borrador (draft) → enviado (sent) → visto (viewed) → parcial (partial) → completado (completed).
- **rule**: The free plan has a monthly limit of 5 requests; once reached, the 'New request' button is disabled and a 'Monthly limit reached' notice appears.
- **fact**: Available actions based on document status include resending reminders, canceling requests (invalidates links), and downloading the signed PDF with its certificate.
