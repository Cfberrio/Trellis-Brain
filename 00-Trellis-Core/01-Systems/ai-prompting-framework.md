# AI-Prompting-Framework

## Canonical Statement

- **process**: A high-quality prompt is constructed using up to 6 components: Task (required), Context, Examples, Persona, Format, and Tone. While not all are required for every prompt, complex tasks benefit from using more components.
- **rule**: AI model selection should be based on the specific task requirements (e.g., reasoning, creative writing, coding) rather than a single 'best' model. Slower, more thoughtful models are preferred for complex strategy and analysis tasks.
