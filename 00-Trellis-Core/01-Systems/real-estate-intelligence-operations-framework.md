# Real-Estate-Intelligence-Operations-Framework

## Canonical Statement

- **process**: The Real Estate Intelligence & Operations framework (Nivel 2) prioritizes connecting existing systems (PMS, Accounting, ClickUp) over immediate replacement, establishing a source-of-truth architecture, and building an intelligence layer for exception monitoring and automated reporting.
- **rule**: Implementation of agentic systems in real estate should follow the principle: Connect before automating, structure before reasoning, observe before acting, and prove value before increasing autonomy.
