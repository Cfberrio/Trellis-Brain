# Content Creation and Editing Standards

## Canonical Statement

- **preference**: Trellis content should utilize a 'hiperprocesado' (highly processed) editing style to demonstrate creative capacity, using visual overstimulation, zooms, and overlays to prevent attention drops.
- **decision**: Content structure for Trellis should follow an 'Impact + Validation + Conclusion' flow: hook the audience first, then justify with micro-arguments, and finally deliver the message.
- **preference**: For brand storytelling, Trellis prefers a cinematic production style with a moderate narrative rhythm that allows the audience to assimilate emotional subtext and philosophy.
