# Content-Buildup-Strategy

## Canonical Statement

- **definition**: Buildup is the phase before delivering core value in content, designed to create attention, curiosity, and emotional response by aligning the audience's state with the value to be delivered.
- **rule**: Content planning must define the type of Buildup (Emotional, Contextual, Explosive, or Observational), the target emotion, and the connection to the core value before production.
- **process**: Buildup effectiveness is validated through the feedback loop: if the audience does not stay, the message is misinterpreted, or connection fails, the Buildup must be adjusted.
