# Content Pillar - Educativo Informativo Diagnóstico

## Canonical Statement

- **definition**: El pilar Educativo / informativo / diagnóstico identifica problemas reales de las marcas con su contenido, explica su origen y muestra la lógica de una mejor ejecución mediante el diagnóstico claro.
- **process**: La estructura base del pilar sigue el flujo: Hook → Problema → Explicación → Reencuadre → Solución parcial o idea clave → Remate.
- **rule**: Este pilar no debe funcionar como tips sueltos; su valor reside en la capacidad de diagnosticar observaciones concretas (ej. por qué el contenido parece publicidad) en lugar de usar frases vacías.
- **fact**: El pilar es flexible y puede abordar errores frecuentes, mitos de contenido, fallas de storytelling, branding, engagement y el uso de IA, utilizando formatos como A-roll, motion graphics o Vox-style explainers.
