# Editor Role Specializations and Standards

## Canonical Statement

- **process**: Editors must design short-form narrative structures using a specific curve: hook (0-1.5s), promise, development, payoff, and loop, incorporating pattern interrupts to maintain retention.
- **rule**: Motion graphics and captions must prioritize hierarchy and legibility for small screens, with timing ensuring subtitles appear just before the spoken phrase.
- **process**: Audio editing for short-form requires balancing voice vs music for mobile intelligibility and using SFX (whoosh, pop, hit) as intentional attention signals.
- **rule**: Editors are responsible for Brand Strategy continuity, ensuring visual consistency in color, look, and B-roll selection while optimizing exports for IG Reels, TikTok, and Shorts.
- **process**: AI tools like Claude Code should be used as a co-pilot to automate repetitive tasks including script generation, naming, briefs, and QA scorecards.
