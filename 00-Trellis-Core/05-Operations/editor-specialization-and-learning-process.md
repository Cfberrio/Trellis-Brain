# Editor Specialization and Learning Process

## Canonical Statement

- **rule**: Each editor must choose exactly one unique specialization to develop depth and team efficiency, avoiding repetition of areas chosen by others.
- **process**: The team holds weekly specialization meetings where editors share concrete improvements, tools, and techniques to elevate output quality and reduce production time.
- **definition**: Editing specializations include: Short-form Narrative Structure, Intentional Transitions, Motion Graphics/Typography, Audio/SFX Design, Brand Strategy/Visual Consistency, Platform Optimization, and Technical QA.
- **rule**: Claude Code is utilized as a co-pilot for all editors to automate repeatable tasks like scripts, captions, QA scorecards, and converting feedback into action lists.
