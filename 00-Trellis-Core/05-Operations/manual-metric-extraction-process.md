# Manual Metric Extraction Process

## Canonical Statement

- **process**: Metric extraction follows a standard flow: enter platform, select brand, filter calendar month, review general metrics, audience, and content, identify top performers, and export data.
- **rule**: Always validate the correct brand, platform, profile, and date range before reading numbers. Use full calendar months only; never use automatic filters like 'last 7 days' or 'this month' (if incomplete).
- **fact**: Essential metrics for all platforms include channel performance, content volume, interactions, follower growth/loss, demographics, traffic sources, and top-performing content.
- **rule**: Avoid common errors: incorrect date ranges, confusing Instagram with Facebook metrics, extracting from the wrong account, mixing organic with paid data, and copying percentages without base numbers.
