# ClickUp Documentation and Reasoning Rules

## Canonical Statement

- **rule**: Information directly applied to a brand (emails, website structure, funnels) must be stored in that brand's ClickUp Space, inside a specific folder.
- **rule**: Decisions, conclusions, and implementation logic (the 'how' and 'why') must be stored in the Trellis ClickUp Space as this represents the company's monetization funnel.
- **process**: Documentation in subtasks must follow a specific 6-point format: 1. What was done, 2. Reasoning, 3. Alternatives discarded, 4. Problems found, 5. Solution, 6. Result.
- **rule**: The 'Rule of WHY': Never report only the 'what'. Documentation must include the reasoning to ensure the knowledge can be packaged and taught.
