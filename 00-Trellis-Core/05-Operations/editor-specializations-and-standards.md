# Editor Specializations and Standards

## Canonical Statement

- **rule**: Editors must master short-form narrative structure, including hooks (0-1.5s), pattern interrupts (zoom, text, beat switches), and pacing to maintain retention.
- **rule**: Motion graphics and typography must prioritize hierarchy and legibility for small screens, with captions timed to appear just before the audio 'hit'.
- **rule**: Audio editing for short-form requires balancing voice vs music for mobile intelligibility and using SFX (whooshes, hits, UI ticks) as attention signals.
- **rule**: Editors are responsible for 'Band Strategy', ensuring visual consistency (color/look), intentional B-roll selection, and platform-specific optimization (IG/TikTok/Shorts).
- **rule**: AI tools like Claude Code should be used as a co-pilot to automate repetitive tasks like scripting, naming, and converting feedback into action lists.
