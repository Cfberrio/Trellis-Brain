# Community Management Posting Process

## Canonical Statement

- **process**: When scheduling social media posts, avoid exact hours (e.g., 2:00); use irregular times like 2:07 or 3:18 to stand out from standard posting blocks.
- **rule**: Use GoHighLevel for most scheduling, but use manual iPhone uploads for TikTok carousels (not supported by TikTok Studio) and Facebook carousels if formatting issues occur.
- **rule**: Verify VPN functionality before publishing if the operator is not physically located in the target market (e.g., Orlando) to ensure correct geolocation signals.
- **process**: Post-publication, manually verify content on each social network to check for formatting errors, crops, or display issues.
