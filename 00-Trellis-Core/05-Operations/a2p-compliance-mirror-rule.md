# A2P-Compliance-Mirror-Rule

## Canonical Statement

- **rule**: A2P Campaign Mirror Rule: The campaign description and user consent language must perfectly mirror the opt-in form's stated messaging types (e.g., if the form mentions both marketing and transactional messages, the campaign description and checkbox language must explicitly state both).
- **fact**: A2P campaign rejections for 'Opt-In Information' are often caused by mismatches between the campaign description and the actual opt-in form content, or by non-functional opt-in URLs.
