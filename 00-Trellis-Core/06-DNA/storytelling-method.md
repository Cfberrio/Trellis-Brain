# Storytelling-Method

## Canonical Statement

- **process**: The Trellis Storytelling Method consists of 5 pillars: Hook (initial promise), Build-up (narrative tension), Value (what the user gains), Payoff (resolution of the hook), and CTA (natural invitation to the next step).
- **rule**: Content pillars must be designed consciously based on the customer's stage (suelo).
- **rule**: CTAs in Trellis must be invitations based on reciprocity, not aggressive sales pitches. If a CTA feels like a pitch, the preceding process failed.
