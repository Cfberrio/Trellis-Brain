# Value-Identification-Framework

## Canonical Statement

- **process**: The Value Identification Framework defines value as the change in a person after consuming content, categorized into five families: Clarity, Relevance, Confidence, Empowerment, and Belonging.
- **rule**: Value must be defined as a user experience, not a brand promise, using the sentence: 'Después de consumir esto, la persona se lleva ______.'
