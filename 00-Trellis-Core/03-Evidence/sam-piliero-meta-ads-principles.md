# Sam-Piliero-Meta-Ads-Principles

## Canonical Statement

- **fact**: Meta Ads campaign structure should separate prospecting, retargeting, and retention to prevent budget competition.
- **rule**: Adding new creative to an existing ad set resets its learning phase; batch creative changes into deliberate resets rather than adding ads incrementally.
- **rule**: When testing interest-targeted ad sets, use only proven ads to ensure the interest is the only variable being tested.
