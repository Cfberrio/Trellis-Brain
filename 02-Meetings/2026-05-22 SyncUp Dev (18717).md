*   **Problemas con el preview y carga de gráficos** Problema
    *   Se discutió que la función de preview tenía dificultades para cargar gráficos pesados, lo que generaba visualizaciones en blanco o incompletas durante las pruebas.
    *   Se resaltó que el comportamiento era diferente en el entorno local (donde se visualizaba correctamente) frente al preview, lo cual afecta la validación del diseño antes del despliegue.

*   **Diseño y funcionalidad de botones y elementos visuales** Decisión
    *   Se debatió la necesidad de mejorar la diferenciación visual de los servicios, utilizando colores (blanco y gris) para indicar qué está incluido y qué no, evitando confusiones al usuario.
    *   Se propuso replicar y estandarizar el botón 'book' en diferentes secciones, incluyendo animaciones como check o X para hacer la interacción más intuitiva.
    *   Se sugirió agregar títulos y elementos gráficos mayores en la sección de add-ons para lograr una presentación más limpia y coherente con el home page.

*   **Lógica de selección de add‐ons y flujo del booking form** Problema
    *   Se revisó en detalle el proceso de selección de extras o add‐ons, incluyendo la capacidad de elegir varios elementos (como quesos, proteínas u otros adicionales) y cómo se reflejaría esto en la base de datos.
    *   Se plantearon inquietudes sobre la complejidad del flujo, la posibilidad de que el cliente pague de más o de menos y la necesidad de ajustar la lógica para que cada selección se contabilice correctamente.
    *   Se destacó la importancia de integrar esta lógica en el proceso de checkout y de vincularla al flujo de selectores para que el usuario entienda qué opciones gratuitas están incluidas y cuáles son opcionales.

*   **Estandarización de keywords y configuración del backend** Idea
    *   Se discutió la necesidad de que los ítems, categorías y modificadores sean configurables y estandarizados desde el backend mediante el uso de keywords.
    *   La propuesta incluía que estos 'keywords' sirvieran para establecer descripciones, alertas visuales y cambios fácilmente modificables sin rehacer la estructura del sistema.
    *   También se abordó la importancia de gestionar la migración de cron jobs y funciones automáticas, para asegurar que tareas críticas (como el envío de SMS) funcionen correctamente.

*   **Gestión del repositorio y colaboración de equipo** Decisión
