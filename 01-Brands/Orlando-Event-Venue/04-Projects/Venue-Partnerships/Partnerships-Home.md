## Partnership Types

### Type 1 — Venue Software Licensing
**Proposition:** other venues use OEV's automation stack (Cloud Amazon + Claude + Whisper + GHL + booking funnels + dashboards) under a RevShare model.

**Model:** 80-20 RevShare based on revenue generated through the system. No implementation cost to the partner; payment scales with their bookings.

**See:** [[01-Brands/Cross-Brand/Real-Estate/2026-05-20-Meeting-Eric|Meeting Eric — venue software product]] for current pitch structure.

### Type 2 — Referral Partnerships
**Proposition:** local businesses (event coordinators, photographers, planners, real estate professionals) refer event hosts to OEV with a custom referral code.

**Model:** $50 off client / $100 partner payout (or credit) per qualified booking.

**See:** [[../../06-DNA/Referral-System|OEV Referral System]] for full rules + payout structure.

### Type 3 — Strategic Co-Investment
**Proposition:** partnerships where OEV co-invests with a property owner or investor on event-space build-out, lease, or expansion.

**Model:** TBD per deal. Currently in discussion with CIG (CV Capital Investment Group) — see [[01-Brands/Cross-Brand/Real-Estate/2026-05-18-CIG-Property-Management|CIG meeting]] for negotiation context.

## How To Add A New Partnership

1. Create a new note in this folder: `YYYY-MM-DD-<Partner-Name>.md`
2. Use the partnership template structure:
   - Partner name + contact
   - Type (software / referral / co-investment)
   - Initial pitch date
   - Status (pending / active / closed / dropped)
   - Financial structure
   - Operational integration plan
   - Reference to source meeting note (in `01-Brands/Cross-Brand/Real-Estate/`)
3. Add to the Active Partnerships table above
4. If venue-software type → cross-link to [[../../06-DNA/Money-Model|Money Model]] expansion path
5. If referral type → cross-link to [[../../06-DNA/Referral-System|Referral System]]
