## Purpose
Practical day-1 guide for a new OEV salesperson. Based on Sebastian's onboarding session with Luis. Use this to get oriented FAST.

## 1. What You Need To Understand First

### What OEV Is
Orlando Event Venue = rentable event space used for:
- Birthday parties
- Baby showers
- Weddings / celebrations
- Corporate events
- Workshops
- Research events
- Community meetings
- Trainings
- Conferences

> The big opportunity: people **already need a space**. Your job = help them understand if OEV fits + guide them to book.

### What Your Role Is
Your role = help people **get to the finish line**.

You are NOT trying to pressure people. You are helping them:
1. Check if their date is available
2. Understand the pricing
3. Understand what is included
4. Pick the right add-ons
5. Book online
6. Pay remaining balances
7. Get answers quickly
8. Feel like OEV is easy to work with

> Luis's main point: this is not complicated sales. If someone has an event and the venue fits, you help them book.

### How You Make Money / Track Commission
You get credit when you handle a customer and they pay.

OEV tracks via **Go High Level tags**. When you handle a customer, you add a tag with your name (e.g., **Sebastian**) to that contact.

Later, when payments are reviewed, customers under your tag are used to calculate your payment/commission.

**Your rule:** If you helped the customer → tag the customer.

### What Customers Usually Need To Know
- Is my date available?
- How much does it cost?
- What is included?
- Can I bring food?
- Can I bring alcohol?
- Do you have tables and chairs?
- Do you have speakers, microphones, screens, or production?
- Can I tour the venue?
- How do I pay?
- How do I finish paying my balance?
- How does setup and breakdown work?

### Basic Sales Flow
Your default flow:
1. Answer the call
2. Ask what date/time they want
3. Ask what type of event they are hosting
4. Check calendar availability
5. Ask if they have seen the website
6. Walk them through pricing on the website
7. Explain hourly vs full-day
8. Explain add-ons if relevant
9. Help them book
10. Follow up in Go High Level
11. Tag them with your name

### What Tools You Need
- ClickUp
- Trellis Chrome profile
- OEV Chrome profile
- Ministries Chrome profile
- Google Calendar
- OEV admin panel
- Go High Level
- Claude
- Obsidian
- Whisper Flow
- Tailscale
- Google Authenticator
- Camera / AC apps

> Big part of your first stage = getting all these logins working correctly.

### What You Should NOT Worry About Yet
Do not worry about mastering everything on day one.

Focus on:
1. Get logged in
2. Know which profile/tool to use
3. Answer calls
4. Check availability
5. Walk people through the website
6. Tag customers
7. Ask Luis when something is unclear

You do NOT need to master advanced scraping, complex AI workflows, or every admin detail immediately.

## 2. Your Core Responsibilities

### 1. Answer Calls
When someone calls, answer naturally:
> "Hi, this is [Your Name] with Orlando Event Venue. How can I help you?"

Goal: quickly figure out what they need.

### 2. Check Availability
Before giving too much information:
> "What date and time are you looking for?"

Then check the calendar.

Do NOT spend 15 minutes explaining the venue if the date is not available.

### 3. Walk Customers Through The Website
Website explains the offer better than freestyling.

Ask:
> "Have you been to our website yet?"

Then walk them through:
- Pricing
- Hourly vs full-day
- Production packages
- Bar services
- Gallery
- Book Now button

## 3. Key Rules (memorize)

| Rule | Why |
|---|---|
| Availability check FIRST | Don't sell unavailable dates |
| Use the website as your visual aid | Better than freestyling |
| Beer & wine only (no liquor) | Compliance + nonprofit rules |
| 4-hour minimum hourly | Pricing floor |
| 50% deposit holds the date | First payment = first commitment |
| Remaining 50% due 15 days before | Per booking policy |
| Tag every customer you handle | Commission tracking |
| Production package required for any A/V use | Tech risk reduction |
| Escalate policy debates to Luis | Don't argue rules with customers |

## 4. Discount Discipline

- Use ONLY pre-approved discount codes (e.g., `GRAD20`)
- Basic offer: ~$100 off
- Multi-day or large bookings: up to 20% off (cap)
- NEVER discount above 20%
- ALWAYS tell the customer what code to use (don't apply silently)
- If unclear → ask Luis before offering

## 5. Common Scenarios + Default Move

| Scenario | Default move |
|---|---|
| Date unavailable | Offer 2 closest alternatives |
| Asks about food | "Bring any licensed caterer" |
| Asks about alcohol | "Beer & wine only, served through approved vendor" |
| Asks about A/V | "Will you need mics / speakers / screens? Then production package required" |
| Asks for a tour | Capture name + best mobile number → "Our admin will text you within 72 hours" |
| Stalls / hesitates | "Totally understand — what's your main concern?" |
| Price objection | Offer pre-approved discount OR present feature downsell |
| Wants alcohol beyond beer/wine | Politely decline + redirect → "Approved vendor handles beer & wine, no liquor" |

## 6. End-Of-Day Checklist
- [ ] All today's customers tagged with your name in GHL
- [ ] All payment links sent
- [ ] All tours requested → admin notified
- [ ] All unclear policy questions → escalated to Luis
- [ ] Wrap notes added to GHL conversation for anyone who didn't close today

## 7. Escalate To Luis When
- Customer wants more than 20% off
- Customer disputes a policy you can't explain
- A/V request that doesn't fit existing production packages
- Booking >90 guests
- Booking that requires hard liquor
- Payment issue you can't resolve in admin
- Anything about contracts, refunds, or legal language
