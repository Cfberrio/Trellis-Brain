## Purpose
Teacher's reference for onboarding new OEV sales people (built from Luis ↔ Sebastian onboarding session). Use this to train someone from zero → handling inbound calls + booking customers + tagging for commission.

## 1. Core Teaching Points

### A. OEV Sales Is Not "Hard Selling"
Salesperson's job = help interested people finish the booking process. Tone: natural, familiar, helpful.

> "We're not selling insurance. We're helping people book a venue if it fits their event."

Salesperson should:
- Answer quickly
- Check availability first
- Guide them through the website
- Explain pricing clearly
- Help them book online
- Use discounts strategically
- Follow up through GHL
- Tag customer correctly for commission tracking

### B. First Filter — Availability
Before giving a full explanation, check the date and time.

**Rule:** Do not waste time selling a date that is already unavailable.

If unavailable, offer alternatives:
> "Unfortunately, we don't have that exact time available, but we may be able to do Friday, Sunday, or a slightly different time on Saturday."

### C. Second Filter — Send Them To The Website
**Key question:** "Have you been to our website yet?"

Then guide them live:
1. Pricing section
2. Hourly vs. full-day booking
3. Production packages
4. Bar services
5. Gallery / tour option
6. Book Now button

> The website becomes the salesperson's visual sales tool.

### D. OEV Pricing Basics
- Hourly rental: **$139/hour** (per transcript; canonical doc uses $140/hour — verify before training)
- Minimum booking: **4 hours**
- Full-day special: **$899**
- Included: 90 chairs + tables, prep kitchen, two bathrooms, main venue space
- Production packages exist as add-ons
- Bar service can be added
- Setup/breakdown can be added as a service
- Customer setup + breakdown happens inside the booking window UNLESS they purchase setup service

> **Needs clarification:** exact current pricing for every production package + bar package should be confirmed in OEV website/admin before training new reps.

### E. Production Packages Are Revenue Opportunities
Production is not just operational. It increases ticket size.

Trainee should ask:
> "Will you need microphones, speakers, screen support, or any kind of presentation setup?"

If yes → walk them through production packages.

### F. Bar Service / Alcohol Rule Is Strict
Outside alcohol NOT allowed unless managed through approved vendor / staff process.

- Beer/wine must be served through approved vendor (venue/nonprofit rules)
- Water/soda/non-alcoholic drinks are fine

> **Training point:** do not debate the policy. Explain it calmly + redirect to approved bar service option.

### G. Discounts Are A Closing Tool
Discounts should feel personal and helpful, not automatic.

| Discount | Use case |
|---|---|
| Basic offer | ~$100 off |
| Multi-day / larger bookings | Up to 20% off (cap) |

> Fixed dollar discounts often feel better than percentages.

Example:
> "I can help you out with a discount code for this booking. Use GRAD20 and it'll take $150 off your reservation."

**Needs clarification:** create official discount approval rules by booking size.

### H. Admin Panel Controls The Booking Workflow
Trainee must learn:
- How to search bookings
- How to view customer details
- How to identify paid vs partially paid
- How to send payment links
- How to move completed events to post-event
- How to cancel if needed
- How to assign staff/cleaning
- How to check event details + add-ons

> OEV does NOT treat the first payment as a separate "deposit." Customer pays half now + remaining half later.

### I. Go High Level Is The Sales Communication Hub
GHL handles:
- Calls (voice + missed)
- Texts
- Emails
- Conversation history
- AI transcriptions
- AI-drafted replies
- Customer tagging
- Commission tracking

> GHL mobile app is where calls come in. If setup disconnects → reconnect inbound calls in settings.

### J. Every Handled Customer Must Be Tagged
If a salesperson handles a customer, they tag the customer with their name. Tag is used to calculate commission.

**Rule:** No tag = hard to track commission.

### K. AI Is A Support Layer, Not A Replacement For Sales Judgment
Claude + Obsidian help with:
- Drafting emails
- Answering policy questions
- Explaining setup/breakdown
- Prospecting lists
- Finding companies (clinical research groups, realtors, speakers, workshops)
- Creating outreach campaigns

But the human still:
- Reviews the answer
- Makes judgment calls
- Confirms policy
- Escalates unclear situations

## 2. Main Learning Curves

| Learning Curve | Why It's Confusing | What They Must Understand | How To Train Faster |
|---|---|---|---|
| Tool overload | ClickUp, Chrome profiles, Tailscale, GHL, Claude, Obsidian, Whisper, calendar, admin, camera/AC apps | Each tool has one main purpose | Create "Tool Map" cheat sheet |
| Multiple Chrome profiles | Personal / Trellis / OEV / Ministries can get mixed up | ClickUp = personal profile; OEV = sales/comms/admin; Ministries = calendar/Pure Space | Loom video: "Which profile to use and when" |
| OEV vs Ministries | Both connected to venue operations | Ministries is mainly calendar/Pure Space; OEV is customer communication/admin | Side-by-side comparison guide |
| Calendar syncing | Same event may appear in both calendars, but edits happen in Ministries | View in OEV, edit in Ministries | Calendar SOP with examples |
| Availability logic | New reps may oversell unavailable dates | Check availability before pricing conversation | Practice 10 booking scenarios |
| Website walkthrough | Reps may explain freestyle instead of using the website | Website is the visual sales tool | Roleplay with website on screen |

## 3. Training Sequence (recommended order)

1. **Setup phase (Day 1):** All logins working (ClickUp / Trellis / OEV / Ministries Chrome profiles / GHL / Tailscale / Google Authenticator / Whisper)
2. **Tool map (Day 1–2):** Which tool for which task
3. **Shadow phase (Day 2–3):** Listen to recorded calls + read transcripts
4. **Roleplay phase (Day 3–4):** 10 booking scenarios (corporate, workshop, baby shower, alcohol question, price objection, unavailable date)
5. **Live-with-backup phase (Day 4–7):** Handle real calls with Luis on standby
6. **Solo phase (Day 7+):** Handle calls + tag customers + send payment links + escalate when unclear

## 4. Quality Checks (post-training)
- [ ] Trainee can navigate website end-to-end while on phone
- [ ] Trainee can pull up admin panel for specific booking
- [ ] Trainee can send payment link in <60 seconds
- [ ] Trainee tags every handled customer with their name
- [ ] Trainee uses approved discount codes only (no improvisation)
- [ ] Trainee escalates alcohol questions / policy debates to Luis

## 5. Common Mistakes To Correct Early
- Trainee tries to sell unavailable dates instead of offering alternatives
- Trainee freestyles pricing instead of using website
- Trainee discounts without approval
- Trainee debates alcohol policy with customer
- Trainee forgets to tag customer → lost commission tracking
- Trainee uses wrong Chrome profile → bookings made in wrong account
