## Offer Ladder Summary
### Entry
Date-Lock Deposit. The first real conversion is the 50% deposit that holds the date.

### Core
Corporate Ready Room. Base venue rental with furniture, prep kitchen, bathrooms, and clear policies.

### Upsells
- Basic Package
- Presentation Pro / LED Package
- Workshop Broadcast Studio / Workshop Package
- Setup & breakdown
- Tablecloth rental
- Security when required
- Bar Service (see OEV-Beverage-Menu): House Beer & Wine ($18/guest), Essential Bar ($25.63/guest), Signature Bar ($32.13/guest), Bespoke Bar ($39.63/guest). Present as "Bar service, handled." — OEV coordinates, client selects package and pays at booking.

### Continuity
Corporate Calendar Membership / recurring room-time structure for repeat business.

### Downsells
- Feature downsell: remove production complexity
- Celebration Lite: compliant celebration path
- Personal Event Content Credit: barter-based promo path

## Offer Logic
Do not scatter these as random offers. They should behave like a ladder:
1. qualify fit,
2. secure date with deposit,
3. choose core rental path,
4. add production or execution vehicles only if the event requires them,
5. save no's with structured downsells instead of ad hoc discounting.

### 2026-05-20 — Non-profit discount offers documented from Luis × Non-Profit Inquiry call

Source: [[01-Brands/Orlando-Event-Venue/04-Training/Source-Calls/2026-05-20_Luis_NonProfit_Inquiry|Source Call 2026-05-20]]

#### Non-Profit Discount — Weekend Cleaning-Fee Waiver (NEW)

**Offer:** $199 discount — effectively waives the cleaning fee on weekend non-profit bookings.

**Who gets it:**
- Registered non-profits (501(c)(3) or equivalent)
- Mission-aligned community organizations (churches, ministries, community groups)
- Saturday/Sunday bookings

**Requires:**
- Proof of non-profit status (501(c)(3) letter, EIN documentation)

**Customer-facing framing (from Luis):**
> "We have a discount we can set up — basically $199, which is in theory the cleaning fee. It doesn't fully cover the cleaning cost on our side because we still have to get staffed to clean, but you guys wouldn't have to pay that line on your booking."

**Sales rep workflow:**
1. Identify customer as non-profit (often surfaces naturally in conversation).
2. Identity-frame OEV ("We're a non-profit ourselves").
3. Offer the discount explicitly: "For non-profits, we have a discount we can set up — it's $199, which covers the cleaning fee on your booking."
4. Request proof of non-profit status before applying.
5. Apply the code in the admin panel before the customer pays.
6. Document in GHL.

#### Non-Profit Discount — Weekday 50% Off Base Rental (existing)

**Offer:** 50% off base rental — Monday–Friday bookings only.

**Who gets it:**
- Registered non-profits with proof of status

**Excludes:** cleaning fee, AV, bar service, any add-on. Base rental only.

#### Standard Discounts (reference)

| Discount | Type | Approval | Notes |
|---|---|---|---|
| Multi-day workshop | 25% off base rental | Rep-approved | 2–3 consecutive days, base rental only |
| Large / repeat corporate | Up to 50% off base rental | Management approval required | Established corporate clients |
| Non-profit weekday | 50% off base rental | Rep-approved with proof | Mon–Fri only |
| Non-profit weekend | $199 cleaning-fee waiver | Rep-approved with proof | Sat–Sun, mission-aligned non-profits |
| Closing incentive | $100 off | Rep-approved | Use sparingly, only when needed to close |

#### Pending reconciliation

**Question for Luis:** can a non-profit booking a Fri+Sat+Sun multi-day event stack the weekday 50%-off-base discount on the Friday booking with the weekend $199-cleaning-fee-waiver on the Saturday and Sunday bookings? Default assumption: yes, since each day is a separate reservation, but verify before applying both.

#### When to offer which

- **Customer says "we're a non-profit"** → ask the days. Offer the discount that matches.
- **Customer is corporate, doing 2–3 day workshop** → offer 25% off base rental.
- **Customer is on the fence, single-day booking** → offer $100 off as a closing incentive only after live-quoting.
- **Customer is large / repeat / partnership** → escalate to Luis for the up-to-50% management approval.

#### Anti-patterns

- Don't lead with discounts. Live-quote first, let the price land, then offer the discount if it fits.
- Don't stack discounts without explicit approval.
- Don't apply non-profit discounts without proof of status — even on a Sunday call with a likeable customer.
- Don't promise discounts in writing before checking the customer's status / category.
