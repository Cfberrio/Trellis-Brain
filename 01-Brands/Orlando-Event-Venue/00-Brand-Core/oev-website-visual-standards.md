# OEV Website Visual Standards

## Canonical Statement

- **rule**: The OEV website implements an alternating background image pattern across all sections (Section 1 -> Image A, Section 2 -> Image B, etc.) to create a dynamic visual rhythm.
- **rule**: Website background images must maintain text readability through contrast checks and the use of translucent panels where necessary (e.g., FAQ sections).
- **fact**: The alternating background pattern uses two specific event space photos with a white veil consistent with the hero section, excluding WebGL-heavy or non-sales surfaces like the 3D tour and admin pages.
- **rule**: Subtle parallax effects via GSAP are applied to website backgrounds but must be disabled when reduced-motion is detected.
