## Customer Journey Ladder (planned sequence of offers)

```
Deposit (Entry) → Rental (Core) → Production + execution add-ons (Upsell)
                                        ↓
                        Repeat-booking membership (Continuity)
                                        ↓
                        Controlled downsells (Feature / Celebration / Personal-Event barter)
```

## 1. Entry / Acquisition Offer — Date-Lock Deposit (50/50 terms)

- **Trigger (eligible when):** Lead confirms date + headcount + fit (capacity/rules) and meets minimum economics (hourly min or day special).
- **Upgrade rule:** The moment they say "we want it," present the deposit as the **"Pay Less Now"** commitment to lock the date.
- **Primary value:** Secure the date without paying 100% today (reduced friction + reduced decision risk).
- **Operational note:** Deposit = first conversion event. Everything else ladders off this.

## 2. Core Offer — Venue Rental (Hourly or 24-Hour Day Special) + Cleaning Fee

- **Trigger:** Deposit paid + reservation confirmed.
- **Upgrade rule:** Choose Hourly (4-hour minimum) OR Day special (24-hour access).
- **Primary value:** Compliant, professional, furnished space that supports the event outcome (corporate/workshop/celebration) with clear constraints.

## 3. Upsell Menu (single menu, not scattered)

### Upsell A — Production Menu (most common profit driver)
**Trigger:** They mention slides / mic / sound / LED / streaming / recording / virtual attendees.

**Upgrade rule:** Any technical equipment usage → production package required.

**Primary value:** Removes tech failure risk + increases event quality.

| Package | Price | Includes |
|---|---|---|
| **Basic Package** | $79/hr | AV + mics + speakers + projectors + tech assistant |
| **LED Package** | $99/hr | Basic + stage LED wall |
| **Workshop Package** | $149/hr | Basic + LED + streaming equipment + streaming tech |

### Upsell B — Execution Add-Ons
**Trigger:** They want help setting up fast, want it to look better, or want safety/compliance support.

**Upgrade rule:** Present only when it solves a stated obstacle (time/effort/risk).

| Add-on | Price | Use case |
|---|---|---|
| Setup & breakdown | $100 flat | Less labor / penalty risk |
| Tablecloth rental | $5 each + $25 cleaning | Aesthetics |
| Security services | (per case) | Event type / headcount |

## 4. Continuity — Corporate Calendar Membership (Recurring Room-Time)

- **Trigger:** After 1 successful corporate booking OR when buyer says they run events monthly/quarterly.
- **Upgrade rule:** If they expect 2+ bookings in next 12 months → present continuity.
- **Primary value:** Priority access + simplified rebooking + member-only economics.

### Structure options (pick 1–2)
- **Bonus Offer:** Priority booking window + fast rebook + included "repeat-event" planning support
- **Discount Offer:** Locked-in 20% preferential rate (production or room blocks)
- **Waived Fee Offer:** Waive/reduce a fee when membership maintained (e.g., cleaning fee waiver conditionally)

## 5. Downsells (salvage non-buyers / reduce churn)

> **Rule:** don't drop price in the moment "just because." Downsell by changing **how they pay** or **what they get**, or **barter discounts for reviews/testimonials/referrals**.

### Downsell 1 — Feature Downsell
**Trigger:** "We don't need all that."
**Rule:** Remove production first; keep core rental.
**Value:** Match budget without losing booking.

### Downsell 2 — Celebration Lite (schedule-filler)
**Trigger:** Not corporate/workshop, but still compliant (beer/wine ok, rules ok).
**Rule:** Present simplest compliant package (space + furniture + optional paid setup).
**Value:** Monetize unused dates.

### Downsell 3 — Personal Event Promo (Baby Showers, Birthdays, Celebrations)
**Trigger:** Personal event inquiry + price objection OR filling low-demand dates without shifting core positioning.

**Predefined conditions (so it doesn't become a default discount):**
- Event type qualifies (baby shower / birthday / small celebration)
- They accept venue rules (capacity, beer & wine only, décor restrictions, setup/breakdown expectations)
- They agree to the promo "trade" terms below

**Trade structure — $100 off in exchange for:**
1. Google review after the event
2. Short video testimonial (20–30 sec) on-site or within 48 hours
3. 1 social post/story tagging the venue
4. Optional: 1 referral intro

**Primary value:** Trade $100 margin for proof + future demand assets that increase perceived likelihood for future buyers.

## Output Sequence
```
Deposit conversion (Entry)
    → Rental (Core)
        → Production + execution add-ons (Upsells)
            → Repeat-booking membership (Continuity)
                ↘ Controlled downsells (Feature / Celebration / Personal-Event barter)
```
