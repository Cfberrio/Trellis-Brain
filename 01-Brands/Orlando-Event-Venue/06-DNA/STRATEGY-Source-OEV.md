## 0) One-Line Model

### Primary (recommended focus: corporate + workshops)
We help corporate teams and local hosts run smooth, professional events via a flexible 90-guest venue + optional staffed AV/LED/streaming production, and we get paid via hourly/day venue rental + cleaning fee + add-on production packages.

### Secondary (optional: social celebrations)
We help celebration hosts throw a stress-free private event for up to 90 guests via a furnished venue with tables and chairs + prep kitchen + optional setup/production add-ons, and we get paid via hourly/day rental + cleaning fee + add-ons.

## 1) Market DNA

### Market / submarket
**Market:** Local event space rental (≤90 capacity) in Orlando.
**Submarkets served today:** corporate gatherings, workshops, celebrations.

### Decision constraints (non-negotiables)

#### Minimum buying power
- **Pricing floor (before add-ons):**
  - Hourly minimum: 4 hours × $140/hr = **$560**
  - Cleaning fee (required): **$199**
  - True minimum to book hourly: **$759**
  - Daily special (24-hour access): $899 + $199 cleaning = **$1,098**
- **To block/hold the date:** 50% deposit on total invoice (rental + cleaning + add-ons). Remaining 50% due per reservation terms.

#### Minimum urgency / pain
- Date-bound event (corporate meeting/training, workshop, celebration) where alternative is costly: scrambling for compliant space, reduced attendee experience, reputational hit, lost ticket/revenue, event cancellation risk.
- Buyer values **certainty + smooth execution** more than "cheapest possible room."

#### Where they can be reached
- **Corporate planners:** office admins, HR/ops coordinators, team leads (local business groups, professional communities, company admin networks)
- **Workshop hosts:** coaches/trainers/creators who run in-person sessions
- **Celebration planners:** people planning birthdays/anniversaries/showers who accept beer & wine only

#### Hard disqualifiers (state upfront)
- Capacity cap: **90 guests max**
- Alcohol: **beer & wine only** (no liquor)
- 4-hour minimum for hourly bookings
- A/V usage requires production package (tech minimums apply)
- Setup/breakdown expectations must be accepted (overtime/restore fees if not)

### "We win here because…"
We win in corporate/workshop events because we reduce planning friction (furnished room + prep kitchen + clear capacity) and increase likelihood of a smooth event via optional staffed production (AV/LED/streaming), while keeping the format flexible (hourly or 24-hour access).

## 2) Avatar

### Best customer definition (tight)
**Single decision maker** planning a **professional, time-bound event** for **up to 90 attendees** who values **smooth logistics + optional production capabilities**:
- corporate ops/HR/admin running quarterly meetings, trainings, team offsites
- workshop host running paid training, recording, or livestream

### Day-to-day pain
Coordinate people, agenda, seating, food, and A/V — and if logistics fail, they look incompetent. Managing constraints: time, setup, cleanup, compliance rules.

### Dream outcome
"I want a **professional space** where everything **just works**, we can **start on time**, and I don't have to worry about **A/V or setup chaos**."

### Top obstacles (ordered)
1. **Uncertainty about compliance/rules** (alcohol, noise, décor, occupancy, penalties)
2. **Setup/breakdown time constraint** (50% rule + overtime risk)
3. **A/V uncertainty** (production package required to use technical equipment; technician minimums)
4. **Total cost clarity** (cleaning fee + add-ons + penalties)
5. **Event execution risk** (who runs tech, who resets room, who ensures space is restored)

### Top objections (ordered)
1. "This seems expensive once I add cleaning + production."
2. "The rules/penalties/cameras feel strict — what if guests mess up?"
3. "I'm worried A/V will be a headache or require extra paid hours."
4. "Alcohol policy doesn't match what I need."
5. "I don't want to spend time on setup/reset."

## 3) Offer DNA

### Offer A (Core) — Corporate Ready Room (4+ Hours)
**Promise:** Secure a compliant, professional space for up to 90 guests with flexible layout + option to add production and setup support as needed.
**Mechanism:** Venue rental + included furniture/amenities + optional production packages + optional setup services.

**Construction (Obstacle → Solution → Delivery):**
- "We need a professional room that fits the group." → Capacity + layout flexibility → Space (up to 90), 90 chairs, 10 tables
- "We need basics handled (bathrooms, prep, etc.)." → Included facilities → Prep kitchen, 2 bathrooms
- "We need food flexibility." → Open catering policy → Bring any licensed caterer
- "Alcohol policy must be clear." → Compliance clarity → Beer & wine only (no liquor)
- "We can't risk surprise rules/fees." → Upfront constraints → Written rules + penalties
- "Setup/cleanup timing stresses us." → Time expectation clarity → Setup/breakdown policy + optional paid setup add-on

**Price:** $140/hr (4-hr min) + $199 cleaning; $899/day + $199 cleaning.
**Terms:** 50% to reserve / block date; 50% remaining per policy.

### Offer B (Upsell) — Presentation Pro (LED + Tech)
**Promise:** Deliver a premium presentation environment with supported A/V.
**Mechanism:** LED Package (includes Basic) + stage LED wall + tech.
**Price:** $99/hr (LED) or $79/hr (Basic) + tech minimums.

### Offer C (Premium Upsell) — Workshop Broadcast Studio (Streaming + Recording)
**Promise:** Run a workshop with streaming/recording/virtual conferencing + dedicated streaming support.
**Mechanism:** Workshop Package (Basic + LED + streaming equipment + streaming tech).

### Offer D (Downsell / Schedule-Filler) — Celebration Lite (Beer & Wine OK)
**Promise:** Clean, compliant venue for personal celebrations (baby showers, birthdays, anniversaries) up to 90 guests with clear rules to avoid penalties.
**Mechanism:** Space + furniture + optional paid setup + optional tablecloth rental.
**Why this exists:** Captures non-ideal demand without positioning the brand as "a baby shower venue." Controlled schedule-filler path.

### Offer E (Barter Downsell) — Personal Event Promo (Advertising-for-Credit)
**Promise:** $100 credit in exchange for specific post-event promotion assets.
**Mechanism:** Discount-as-ad-buy (trade margin for proof + future demand).
**Terms (predefined; not automatic):**
- $100 credit applies only if they complete:
  1. Google review
  2. 20–30 sec video testimonial
  3. 1 social post/story tagging the venue
  4. Optional referral intro
- Offered only when: personal event lead + price objection OR intentionally filling low-demand dates AND they accept rules.

## 5) Lead DNA

### Lead Magnet Strategy (built around "availability calls" + automation + voice agent)

#### Narrow problem
Inbound Google/directory callers ask:
> "Is my date available, what will it cost, and will my event be allowed (rules)?"

Naturally leads to next step: **lock the date + execute without issues/fees.**

#### Lead Magnet #1 (Primary): Instant Availability + Quote Pack
**Goal:** turn "availability callers" into an engaged lead.

**Includes:**
- Date/time window request
- Auto-calculated minimum economics (hourly min vs day + cleaning + add-ons)
- Quick compliance snapshot (beer/wine allowed; no hard liquor; key rules)
- Layout chooser (90 chairs / 10 tables templates)

**Formats:** SMS link (fastest for callers), 1-page PDF, 60–90 sec walkthrough video.
**CTA:** "To block the date: 50% deposit today (remaining 50% per policy)."

#### Lead Magnet #2 (Controlled downsell): Personal Event Host Kit (Baby Shower Examples)
**Not main positioning — personal event conversion tool.**

**Includes:**
- Decoration + cleanup checklist (no glitter/confetti)
- Setup/breakdown timeline template (avoid overtime)
- Baby shower layout templates (gift table, photo area, seating flow)

**Promo trade ($100 credit) attached cleanly — not spontaneous discounts.**

### Automation Blueprint (CRM-first, voice-agent–driven)

**Inbound call (voice agent):**
- Capture 4 fields live: date/time window, guest count, event type, A/V needs
- Send Availability Pack link via SMS during call
- Capture event details in CRM

**After opt-in:**
- Confirm availability (or offer 2 closest alternatives)
- Send quote summary + what's included + key rules
- Ask for deposit to block date only when qualified (Floor 4+)

### Follow-up cadence (automated)
- **Day 0:** availability confirmation + quote + deposit CTA
- Same day: 2 nudges if no response (text first; voice agent/human call second)
- Next 2 days: 2 touches/day
- Next 4 days: 1 touch/day
- Then: long-term nurture

### Scarcity / Urgency (Floor 6, only when real)
**Use only when one of these flags is true:**
- ✅ `hold_expires_at` is within 24h / 6h
- ✅ `competing_inquiry = true` (logged for same slot)
- ✅ `tech_resource_needed = true` and tech availability is limited
- ✅ peak-date inventory objectively tight (weekends/holidays)

**Examples:**
- Hold expiring: "Reminder: the hold for [date/time] expires at [time]. To lock it: 50% deposit → [link]."
- Competing inquiry: "Heads-up: another inquiry came in for [date/time]. The date is confirmed with deposit → [link]."
- Tech constraint: "To guarantee LED/streaming on [date], we also need to reserve the tech slot. Confirm here → [link]."

#### Step 0 — Capture info FIRST (30 seconds)
1. "What's your **name**?"
2. "Perfect, [name], is **(XXX) XXX-XXXX** the best number to reach you?"
3. "What's the best **email** for your receipt + agreement?"

#### Step 1 — Confirm availability inputs (60–90 seconds)

- Guest count (≤90)
- Event type
- Alcohol (beer & wine only fit)

#### Step 2 — Present next step (binary + simple)
"Great — if it's available, the next step to **hold the date** is the **50% deposit** through the website checkout."

#### Step 3 — Convert call → SMS thread (while still on phone)
- "I'm texting you the booking link + the key details now."
- Send SMS #0 immediately.
- "Do you have a minute right now? I can stay with you while you complete the checkout."

#### Step 4 — If they stall (one default close)
- "Totally understand — **what's your main concern?**"

### Tour Handoff (Admin-run)
- Capture name + best mobile number (confirm + repeat-back).
- Set expectation: "Our admin runs tours and will text/call you to confirm a time."
- **Internal policy (non-negotiable):** admin offers tour times within **72 hours** because closer appointments show higher.

### AI SMS Bot Rules

**Always on:**
1. **Thread-first:** keep conversation in SMS.
2. **Stop-on-reply:** any inbound question becomes an answered thread (no blasting over active conversation).
3. **Decision power:** when unclear, ask "what's your main concern?"
4. **Truthful scarcity only:** "date is held once deposit is paid" (no fake "others are booking").
5. **Transparent reminders:** people don't mind reminders; they mind being lied to.

**Triggers:**
- If they ask **price / availability / rules** → answer + send booking link.
- If they say **tour** → collect phone, confirm, tell them admin will follow up.
- If they show intent but hesitate → "what's your main concern?" then resolve.
- If unqualified (liquor, >90, won't follow rules) → exit cleanly.

## 8) Retention + Expansion DNA

### Retention driver
For a venue: **repeat bookings + referrals.**
- **Predictable experience** (no surprises)
- **Clear expectations** (rules + costs + timelines)
- **Fast rebooking** (make it easy to repeat)

### Churn triggers (early cancellation predictors)
- Haven't replied to the onboarding form (missing details = low commitment)
- Haven't chosen Hourly/Daily or confirmed timeline (uncertainty)
- Resist rule acknowledgement (future fee conflict)
- Final 50% not planned (payment friction)
- AV needs unclear

### Expansion paths

**Upsell rules:**
- Upgrade to Daily when: setup/teardown heavy OR long access needed OR multiple segments
- Production package when: AV/LED/streaming required
- Setup/Breakdown service when: client wants convenience or tight timeline
- Security when: event type or headcount suggests higher risk

**Cross-sell rules:**
- Tablecloths, paid setup, add-on tech hours, extra cleaning services

**Downsell rules:**
- Personal events promo (baby showers, birthdays) under predefined conditions

### LTV Levers (Crazy 8 mapping)
1. **Increase price** → periodic price tests (planned, not random)
2. **Decrease cost** → staffing efficiency + standardized checklists
3. **Cross-sell** → add-ons (setup/tablecloths/security)
4. **Buy again** → corporate recurring meeting block
5. **Buy more at same time** → push Daily when it fits
6. **Buy a better version** → production packages (Basic → LED → Workshop)
7. **Downsell quantity** → smaller personal-event options
8. **Downsell quality** → budget version to salvage price objections

## 11) Referral System (full canonical)

### A "Qualified Referral" requires all four
1. **New lead** (not already in OEV CRM under same phone/email)
2. Fits venue constraints (≤90 guests, rules accepted, beer & wine only)
3. Pays the **50% deposit** to block the date
4. Event reaches **Post-Event inspection complete** (not cancelled / not chargeback)

### Reward structure
**Partner chooses one:**
- A) Cash payout (paid after event closes)
- B) OEV credit (higher value, protects cash)

**Tier 1 — Corporate / Workshop (ideal):**
- **$100 cash** or **$150 OEV credit** per qualified booking

**Tier 2 — Personal events (schedule-filler):**
- **$50 cash** or **$75 OEV credit** per qualified booking

**Bonus (only when it increases margin):**
- If booking includes a production package for 3+ hours: **+$25 cash** or **+$40 credit**

### Payout timing
- Reward earned when deposit paid.
- Paid **7 days after event end** AND post-event inspection complete (Closed / Review Complete).
- Cancelled / chargeback = no payout.

### Stacking rules
- Cannot combine partner referral reward with $100 Baby Shower Content Credit (pick one).
- Cannot stack with other discounts unless approved.

### Capacity Controls
- **Monthly cap per partner:** max **5 qualified payouts/month**
- **Total program cap:** max **25 qualified payouts/month**
- **Last-minute rule:** bookings inside **7 days** of event date = no referral payout

### Green Inventory Window
Referral rewards apply only if event date is:
- **14+ days out** OR
- **Mon–Thu dates** (typically easier ops)
- Prime high-demand days (Fri–Sun) inside 14 days: accept booking, but no referral payout.

### Referral methods

**Method A (recommended):** Unique referral link
- Format: `oev-booking.com/availability?ref=PARTNERNAME`
- Lead submits date/time → CRM tags lead automatically

**Method B (fallback):** Text intro template
- Partner texts OEV: Name + Phone + Date/Time + Event type + Guest count
- Admin tags: `REF–Partner–[Name]`

### Partner-Facing One-Message Script
> "If you need a venue in Orlando (up to 90 guests), Orlando Event Venue can confirm availability fast.
> Use this link to check dates + get pricing: **[partner link]**.
> Once you place the **50% deposit**, the date is blocked. Beer & wine are allowed (no liquor)."

### CRM fields (required)
- `ref_partner_id`
- Tag: `REF–Partner–[Name]`
- `ref_reward_type` (cash / credit)
- `ref_reward_amount`
- `ref_status` (pending / earned / payable / paid)

### Automation rules

| Trigger | Actions |
|---|---|
| Deposit paid → Confirmed | Set `ref_status = earned`; create task "Confirm staff assignment" |
| Post-Event | Trigger inspection checklist; if complete → move to Closed/Review Complete |
| Closed/Review Complete | If `ref_status = earned` → set `ref_status = payable`; auto-generate payout request; notify partner |
| 7 days after Closed/Review | Pay cash / issue credit; set `ref_status = paid` |

### Cashflow Budget Guardrail
- **Max referral payouts/month = $1,500 cash** (15 corporate bookings × $100)
- Credits can be higher (future spend) but cap them too (e.g., **$2,250 credit/month**)
- If caps hit: continue accepting referrals, mark as "rollover" to next month's payout queue.
