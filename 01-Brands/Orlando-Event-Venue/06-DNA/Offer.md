## Offer A (Core) — Corporate Ready Room (4+ Hours)

**Promise (measurable):** Secure a compliant, professional space for up to 90 guests with a flexible layout + the option to add production and setup support as needed.

**Mechanism:** Venue rental + included furniture/amenities + optional production packages + optional setup services.

### Obstacle → Solution → Delivery
| Obstacle | Solution | Delivery |
|---|---|---|
| "We need a professional room that fits the group" | Capacity + layout flexibility | Space (up to 90) + **90 chairs** + **10 tables** |
| "We need basics handled (bathrooms, prep)" | Included facilities | Prep kitchen + 2 bathrooms |
| "We need food flexibility" | Open catering policy | Bring any licensed caterer |
| "Alcohol policy must be clear" | Compliance clarity | Beer & wine only (no liquor) |
| "We can't risk surprise rules/fees" | Upfront constraints | Written rules + penalties |
| "Setup/cleanup timing stresses us" | Time expectation clarity | Setup/breakdown policy + optional paid setup add-on |

### Stack rule
Corporate Ready Room → add production only if A/V, mics, LED, streaming needed (Offer B/C). Add execution add-ons only if they reduce time/effort/risk.

### Proof package
- Corporate setups (boardroom/classroom), workshop clips, before/after room flips
- Testimonials/reviews
- "What's included" walkthrough video

### Guarantee
> "If included equipment we provide fails during contracted tech hours and we can't restore function, you receive a defined credit."
(Only promise what you control.)

### Price + packaging
- $140/hr (4-hr min) + $199 cleaning
- $899/day + $199 cleaning
- **Terms:** 50% to reserve, 50% remaining per policy

## Offer B (Upsell) — Presentation Pro (LED + Tech)

**Promise:** Deliver a premium presentation environment with supported A/V so it looks and sounds professional without tech chaos.

**Mechanism:** LED Package (includes Basic) + stage LED wall + tech.

### Obstacle → Solution → Delivery
| Obstacle | Solution | Delivery |
|---|---|---|
| "Our slides need to look premium" | LED environment | LED wall + supported playback |
| "We can't risk A/V failure" | On-site support | Tech assistant (per package) |
| "We need mic/speakers/projection" | Bundle essential A/V | Basic Package via package selection |

### Price
- $99/hr (LED) or $79/hr (Basic) + tech minimums per policy

## Offer C (Premium Upsell) — Workshop Broadcast Studio (Streaming + Recording)

**Promise:** Run a workshop that supports streaming/recording/virtual conferencing with dedicated streaming support.

**Mechanism:** Workshop Package (Basic + LED + streaming equipment + streaming tech).

### Obstacle → Solution → Delivery
| Obstacle | Solution | Delivery |
|---|---|---|
| "We need streaming/recording" | Streaming-ready setup | Workshop package gear + streaming tech |
| "We don't have a producer" | Dedicated support | Streaming tech included |
| "We need both immersive + broadcast" | Bundled environment | Basic + LED + Streaming combined |

### Price
- $149/hr (Workshop)

## Offer D (Downsell / Schedule-Filler) — Celebration Lite (Beer & Wine OK)

**Promise:** A clean, compliant venue for personal celebrations (baby showers, birthdays, anniversaries) up to 90 guests, with clear rules to avoid penalties.

**Mechanism:** Space + furniture + optional paid setup + optional tablecloth rental.

### Obstacle → Solution → Delivery
| Obstacle | Solution | Delivery |
|---|---|---|
| "We need a place for a baby shower/birthday that won't be a headache" | Clean, compliant venue | Space + chairs/tables + rules clarity |
| "We want it to look nice fast" | Simple décor support | Tablecloth rental option |
| "We don't want to do heavy lifting" | Reduce effort | Paid setup/breakdown add-on |

**Why this exists:** Captures non-ideal demand **without positioning the brand** as "a baby shower venue." Controlled schedule-filler path.

## Offer E (Barter Downsell) — Personal Event Promo (Advertising-for-Credit)

**Promise:** $100 credit in exchange for specific post-event promotion assets.

**Mechanism:** Discount-as-ad-buy (trade margin for proof + future demand).

### Terms (predefined, not automatic)
$100 credit applies ONLY IF they complete:
1. Google review
2. 20–30 sec video testimonial
3. 1 social post/story tagging the venue
4. Optional referral intro

Offered only when: personal event lead + price objection OR filling low-demand dates AND they accept rules.

## Non-Profit Discount
Non-profits receive **50% off base rental on Monday–Friday bookings**.
