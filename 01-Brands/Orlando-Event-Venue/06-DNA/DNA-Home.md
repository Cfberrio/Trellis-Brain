## Purpose
Strategic skeleton of Orlando Event Venue: where it plays, who it serves, what it sells, how money flows, how leads convert, how the event is delivered, how customers stay, what to measure, how to scale, how referrals work.

## One-line Model

### Primary (recommended focus: corporate + workshops)
We help corporate teams and local hosts run smooth, professional events via a flexible 90-guest venue + optional staffed AV/LED/streaming production, paid via hourly/day venue rental + cleaning fee + add-on production packages.

### Secondary (optional: social celebrations)
We help celebration hosts throw a stress-free private event for up to 90 guests via a furnished venue with tables + chairs + prep kitchen + optional setup/production add-ons, paid via hourly/day rental + cleaning fee + add-ons.
