## KPIs Tied To Each System

### Acquisition KPIs
- Inbound leads by source (Google / directory / other)
- Missed call rate
- % leads captured into CRM (phone + name captured)

### Conversion KPIs
- Lead → **Confirmed availability**
- Confirmed → **Hourly/Daily chosen**
- Chosen → **Deposit paid**
- Deposit paid → **Event held** (cancellation rate)
- Review request → **Review completed**

### Fulfillment KPIs
- Time Pending → Confirmed (SLA)
- Time Confirmed → Pre-Event Ready (staff assigned SLA)
- % add-ons locked ≥48h before event
- Inspection SLA completion (same day / next day)

### Economics KPIs
- Average booking value
- Attach rate by add-on (production / setup / etc.)
- Gross margin per booking (or LTGP if tracked)

## 5 Weekly Numbers (track consistently across brands)
1. **Inbound leads captured** (count)
2. **Decision Packet delivered** (% of inbound)
3. **Deposit conversion rate** (captured → deposit)
4. **Average booking value + attach rate** (core + add-ons)
5. **Cancellation rate + review completion rate** (quality + growth)
