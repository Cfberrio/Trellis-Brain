# Missed Call Recovery System

## Canonical Statement

- **process**: OEV implements a 'Missed Call Recovery' system using a GHL Voice Agent to handle incoming calls when staff are unavailable. The system captures lead data, provides immediate SMS booking links (Lovable), and triggers a short nurture sequence for leads who do not book immediately.
- **rule**: The Voice Agent must obtain explicit consent ('¿Te puedo enviar un texto con el link y la info?') before sending SMS communications to ensure compliance.
