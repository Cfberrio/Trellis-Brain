# OEV Technical Infrastructure Rules

## Canonical Statement

- **rule**: For new OEV projects, a database is only required if the site involves reservations, payments, or user accounts. Informational sites (pages, photos, contact forms) should not use a database to avoid unnecessary monthly server costs.
