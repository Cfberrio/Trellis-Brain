# Email Draft Workflow

Email inbound is usually a **multi-question inquiry** (nonprofit dinner FAQ, corporate AV spec, capacity + policy). The move: answer each question, don't lose one, and pull complex quotes onto a call.

## Steps
1. **Parse every question.** Long emails bundle 5–8 asks (availability, pricing, catering, AV, parking, deposit). List them internally so none is dropped.
2. **Open warm** with the first name: "Hi Bianca," / "Good morning Olha!"
3. **Answer each ask** with a number or a ✓ line. Group by their categories if they used them.
4. **Reframe anything impossible** (over 90 guests) before quoting — restate the max, don't over-promise.
5. **State fees plainly** inline ($199 cleaning, $199 setup + $199 breakdown, 3.5% card).
6. **Give the 3 booking inputs** if a real quote is needed and any are missing (date, start/end, headcount).
7. **Route booking** → orlandoeventvenue.org/book. **Route a complex quote** → offer a call.
8. **Sign** "— Orlando Event Venue Team" and drop 407-974-5979.
9. **Attach** the estimate when a quote is ready; note what's still pending (e.g. "the only thing missing is food & beverage").

## Structure template
```
Hi [First name],

[Warm one-liner — thanks / hope you're well.]

[Direct answer block — one ✓ or number per question:]
• [Question 1] → [answer + number]
• [Question 2] → [answer / ✓ list]
...

[Fees, stated plainly.]

[Missing booking inputs → ask for date + start/end time + headcount.]

[Next step: book at orlandoeventvenue.org/book  OR  "we can hop on a quick call to go over everything."]

— Orlando Event Venue Team
407-974-5979
```

## Handling the common email types
| Type | Handling |
|---|---|
| **FAQ dump** (dinner, many Qs) | Answer inline; reframe if over 90; give $140/hr + $899 daily + included list; route to /book. |
| **Corporate AV spec** (TaxDome-style) | Send an itemized **estimate attached**; flag gaps honestly ("we don't have wireless mics on-site, will bring from the auditorium at no cost"); state $199 setup + $199 breakdown; offer a call. → [[07-escalation-rules]] |
| **"What does [package] include?"** | Answer with a ✓ checklist; confirm what the tech/DJ does; state the hourly total. |
| **Pricing + hours/cutoff** | Give hourly + daily; confirm the block ("9pm–2am is fine, 5-hour block, $700 + $199 cleaning"). |
| **Tour request** | → [[03-tour-follow-up]] |
| **Dispute / policy pushback** | Keep the written reply short; resolve live. → [[07-escalation-rules]] |

## Deliverability guardrails
- OEV recaps/codes/receipts are known to **land in spam**. When emailing something the client is waiting on, **also state the key value in the body** (the code, the amount) so it survives even if an attachment is missed.
- If a client says "I can't see it in Gmail," **confirm the exact address** and resend; offer to text the critical bit.

## Don'ts
- Don't answer 6 questions and silently skip the 7th.
- Don't quote a large/custom event without escalating.
- Don't send an attachment as the *only* copy of a code or amount.
