# OEV SMS Communication Playbook

## Canonical Statement

- **rule**: OEV SMS communications should be energetic, clear, and logistics-aware, avoiding corporate fluff and emojis unless used by the client first. Messages should ideally be ≤160 characters.
- **process**: SMS inquiries regarding alcohol must never use negative phrasing like 'we don't allow'; instead, frame as 'Bar service is available as a paid add-on — we handle the coordination.'
- **rule**: Never share venue access codes via SMS more than 24 hours before an event; refer clients to their confirmation email for earlier requests.
- **process**: Qualify low-budget leads quickly via SMS: if the budget is below the minimum (~$759 for 4hrs + cleaning), provide a clean exit stating the minimum booking cost.
- **rule**: SMS agents must flag messages for human intervention if they contain complaints, refund requests, disputes, injuries, or legal threats.
