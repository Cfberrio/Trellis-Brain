## Brand Summary
Reliable Venues is a B2B service brand that sells **systems-driven venue revenue operations** for event venues. RV is the **revenue operator** — not an agency, not a software vendor, not a consultant.

The promise: **install + run the inquiry → deposit → booked-calendar layer** so bookings stop depending on the owner or a fragile staff member, paid on **incremental booked revenue above baseline**.

## Core Promise
- predictable growth
- less admin stress
- more consistent guest experience
- automated booking + lead handling
- centralized operations for owners + teams

## Operating Reality
RV sells a **done-for-you operating system** built around:
- BookingOS — pipeline + AI first response + follow-up + deposit automation
- DemandOS — required minimum demand layer (Foundation tier; Growth + Dominate upgrades)
- Admin + staff dashboards
- CRM + automated messaging
- Lead funnels + campaigns
- 24/7 responsiveness through automation

## Primary Business Goal
Move qualified venue operators into a **Venue Scaling Roadmap call** booked through Go High Level → Install Month (Trial With Penalty) → Month-2 revshare activation.

## Commercial Model
- **Revshare on incremental booked revenue above baseline**, paid via:
  - Operator % by stage (15% → 5% as venue scales)
  - Required Foundation DemandOS (+5%) — Growth (+8%) — Dominate (+10%)
- Performance-aligned. No traditional retainers.
- See [[01-Brands/Reliable-Venues/06-DNA/Money-Model|Money Model]] for the full ladder.

## Proof-of-concept venue — OEV
Orlando Event Venue runs the full BookingOS + DemandOS stack live. OEV is the case study + walkthrough used in every RV sales motion.

See [[01-Brands/Reliable-Venues/03-Evidence/OEV-Case-Study|OEV Case Study]] and [[01-Brands/Orlando-Event-Venue/04-Projects/Venue-Partnerships/Partnerships-Home|OEV Venue Partnerships]].

## Important rule for this brand
RV should be modeled as a **revenue-operator service brand**, not as a restaurant, venue, or sports brand. Notes route back to:
- inquiry → deposit conversion mechanics
- BookingOS + DemandOS installation
- venue operator pain points
- baseline → uplift case-study proof
- ascension path (Directory Listing → Website → Voice Agent)
