## Entry point — what they do first

- Submit a form (website / "Get quote" / "Book a call")
- Download / claim something (lead magnet / checklist / pricing guide)
- Reply to outreach (email / SMS / DM)
- Ask a question (inbound SMS / IG / website chat)

## Path — opt-in → nurture → call/checkout → onboarding

1. **Opt-in captured** (email / phone) → tag + source logged
2. **Instant confirmation** → "Here's what happens next" + CTA
3. **Nurture** (multi-touch) → build trust + push to call or checkout
4. **Conversion moment** — Book call (B2B / high ticket) OR Pay / checkout (simple offer)
5. **Onboarding** → intake form + kickoff scheduling + access requests + "Day 1 plan"

## Nurture system

### What gets sent (minimum set)
- **Message 1 (instant):** confirmation + 1 quick win + CTA (book call / pricing / next step)
- **Proof:** 1–2 short case studies (before / after, numbers, screenshots)
- **Pain-to-solution:** "Here's what's breaking your results + how we fix it"
- **FAQ / objections:** answers to top concerns before they ask
- **Direct ask:** "Want me to take a look / run a quick audit / show you the plan?"
- **Last-chance nudge:** "Spots / availability / this week only" (real constraint only)

### How often
- **Days 0–10:** 6–8 touches total (mix email + SMS; add 1 voicemail if calls)
- **Weeks 2–8:** 1 touch / week (value + CTA)
- **After:** 1–2 touches / month (newsletter + "still need help?")

### For how long
- **Short nurture:** 10 days (push to decision)
- **Long nurture:** 60–90 days (keep warm if timing isn't right)

### What it's meant to improve
- **Show rate:** confirmations + reminders + "what to prepare"
- **Response rate:** simple questions, easy replies ("1/2/3")
- **Close rate:** proof, clarity, risk-reversal, removing uncertainty

## Sales system

### Qualification rule
**YES if:**
- Clear pain + stakes (money / time / stress)
- Decision maker (or joins next call)
- Timeline real (now–30 days)
- Budget range feasible (not "shopping only")
- Can implement (access, tools, willingness)

**NO if:**
- "Just curious" + no timeline
- No authority + can't bring decision maker
- Wants free consulting endlessly
- Not aligned with offer scope

### Sales steps

**Speed-to-lead rule:** respond within **5–15 minutes** when possible (alone moves response / close rates).

### Call #1 — Discovery (15–25 min)
1. Set frame: why we're here + time check
2. Current situation: what's happening right now
3. Pain + cost: what it's costing (missed $, time, stress)
4. Goal: what "winning" looks like + timeline
5. Fit check: confirm scope + decision process
6. Next step: book close call OR send checkout link

### Call #2 — Close (25–45 min)
1. Recap their goals + pains (make them say "yes")
2. Present plan (3 steps, simple)
3. Offer + timeline + deliverables
4. Price + terms + risk reversal
5. Close question: "Do you want to start today or this week?"
6. Collect payment / signed agreement → schedule onboarding

### Follow-up rules
- **No-show:** instant text + reschedule link, then 24h later one more attempt.
- **"Think about it":** set decision date on the call + follow up exactly then.
- **No reply after proposal:** 48h → 4 days → 7 days (3 touches max), then drop to nurture.

## Objection handling — top 5 + responses

### 1. "It's too expensive."
- "Totally fair. Compared to what it's costing you each month, what feels off — cashflow right now, or you're not convinced on ROI?"
- Then: tie to numbers + offer smaller start or clear "not a fit."

### 2. "Not the right time."
- "What would need to be true for it to become the right time?"
- If real constraint: schedule start date + deposit. If not real: bring back pain cost.

### 3. "I need to talk to my partner / team."
- "Perfect — who needs to say yes, and what do they need to feel confident?"
- Book a decision call with them present. Don't "wait and hope."

### 4. "We already have someone / a system."
- "Great. What's working, and what's still broken?"
- If still in pain: "So you don't need 'a system' — you need *a result*. That's the gap we solve."

### 5. "How do I know this will work?"
- "You don't need certainty — you need a clear plan + proof + a risk-controlled start."
- Use: case study, process clarity, milestone checkpoints, guarantee / risk reversal (only if truly offered).

## Decision path — lead → cash

```
New lead captured → tag source + start nurture
  ↓
Books call → pre-call reminders → show / no-show branch
  ↓
If show → qualify
  ├── If qualified → close call / checkout → pay → onboarding
  └── If not qualified → long nurture or disqualify
Doesn't book by Day 10 → long nurture (weekly) until they respond or unsubscribe
```
