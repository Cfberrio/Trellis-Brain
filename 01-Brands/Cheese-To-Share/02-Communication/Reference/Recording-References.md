## Purpose

Curated set of external Instagram reels used as **visual / format references** when shooting CTS content. Each reference has a working title that maps to a pillar idea or hook concept.

## How to use

- Open the linked reel before a shoot to lock the format, pacing, or hook framing.
- Don't copy literally — adapt format to the CTS universe (kitchen, team, product, customer).
- Treat as a moodboard, not a script.
