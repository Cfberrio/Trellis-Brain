## Purpose

Hub for time-bound CTS initiatives — partnerships, campaigns, special events, expansion experiments. Each project is a discrete chunk of work with its own goal, status, and owner.

Project notes should include:
- Goal + success criteria
- Status + stage
- Owner + collaborators
- Financial structure (if applicable)
- Operational integration plan
- Reference / source meeting note links

## Project types that fit here

- **Brand partnerships** — co-marketing, venue partnerships, vendor collabs
- **Catering retainers** — recurring corporate / monthly client deals
- **Holiday campaigns** — Christmas, 4th of July, Latin Night, etc.
- **Product launches** — new menu item, new station, new package tier
- **Geographic / community expansion** — events outside Avalon Park
- **DTC / pickup line** — board kit, holiday box, etc. (see [[01-Brands/Cheese-To-Share/06-DNA/Scale|Scale]] Stage 3)

## What does *not* belong here

- Daily operations → `05-Operations/`
- SOPs → `05-Operations/SOPs/`
- Strategic positioning → `06-DNA/`
- Marketing content production → `01-Systems/Marketing/`
