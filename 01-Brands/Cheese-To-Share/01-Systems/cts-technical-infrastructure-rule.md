# CTS Technical Infrastructure Rule

## Canonical Statement

- **rule**: New website projects should not include a database server unless strictly required for functionality like user accounts, payments, or reservations. Informational sites (pages, photos, contact forms) should be built without a backend to avoid unnecessary monthly operational costs.
