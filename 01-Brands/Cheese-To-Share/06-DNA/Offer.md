## Offer DNA

CTS monetizes through 4 layers:

1. **Everyday menu demand** — walk-in / pickup / delivery via third-party apps + direct.
2. **Catering packages** — event-based, $25/person base.
3. **Premium add-ons / live stations** — staff service, themed setups, live dessert.
4. **Repeat / referral behavior** — repeat event hosts + share-of-mouth.

## A) Primary Offer — Catering Package (Events)

**Base price:** $25 / person
**Includes:** 7 cheeses + 4 meats
**Minimum:** 30 people (minimum for cheese board / table service)

> [!info] Formula
> `# guests × $25 + (setup optional) + (staff optional) + (stations optional)`

The base is Mediterranean / European-style **grazing tables, cheeseboards, and sharable menus** designed so guests **pick, share, and live the experience**.

## B) Package Stack

| Package | What's included | Ideal for |
|---|---|---|
| 1 — Catering Only (Pickup / Drop-off) | $25/person base only | Office, meetings, when host already has table set |
| 2A — Catering + Setup Standard | Base + $400 setup | Events where look matters but no theme |
| 2B — Catering + Setup Premium (Themed) | Base + $600 setup | Birthdays, brand events, themed aesthetic |
| 3 — Catering + Setup + Staff | Above + waiter | Premium attended experience |
| 4 — Catering + Stations | Base + dessert / experience stations | "Wow moment" events |

## C) Upgrades / Optional Add-Ons

**Staff**
- Waiter / mesero: **$25 / hour**

**Stations**
- Tiramisu station
- Strawberry Dubai / Fresa Dubai station
- Candy station
- Tiramisu (standalone)
- Chocolate fondue
- Cheese fondue
- Cheese cones (price pending)

> Live dessert station is the **lead hero element** for ads — "the dessert everyone stops for."

## D) Booking Conditions

1. **Advance notice**
   - Standard event: 1 week
   - Customized / themed: 15 days
2. **Payment**
   - 50% upfront to reserve date
   - 50% balance 24 hours before event
3. **Minimum:** 30 people for board / cheese service
4. **Quote authority:** all quotes sent by Luis Torres
5. **Process:** client calls to coordinate + sends reference photos (their references or desired setup)

## What makes the offer strong

- Live, on-site dessert preparation isn't common in Orlando — creates "phones come out, everyone watches" moment.
- Grazing table format is visually shareable → built-in UGC.
- $25/person entry is digestible to both private hosts and corporate planners.
- Setup tiers ($400 / $600) create natural upsell ladder.

## What stays true

- CTS does not compete on "cheapest catering." Lead with experience + presentation.
- Don't quote without confirming guest count, date, and event style.
- Don't move ahead without 50% deposit.
