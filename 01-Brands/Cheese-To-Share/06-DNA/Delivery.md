## What CTS actually delivers

CTS delivers across **two operational lanes** that share the same kitchen but follow different fulfillment patterns.

### Lane A — Restaurant operations (everyday)
Walk-in, dine-in, pickup, app delivery. Standard restaurant flow:
- daily prep
- station execution at order
- presentation per menu standard
- pickup / dine-in service

### Lane B — Catering operations (event-based)
Booked events follow a multi-step fulfillment path that begins **before** the event day.

## Catering lifecycle

```
Deposit → Prep window → Sourcing → Production → Transport → Setup → Service → Breakdown → Balance settled
```

### Phase 1 — Prep window (1 week standard, 15 days themed)
- Confirm final guest count
- Confirm menu selections
- Confirm setup details (theme, props, station)
- Source ingredients

### Phase 2 — Sourcing
- Cheeses (7 minimum per board)
- Meats (4 minimum per board)
- Fruits (seasonal)
- Crackers / panes / toasts
- Station-specific ingredients (tiramisu, fondue, Dubai strawberry, etc.)
- Decor / props for themed setups

### Phase 3 — Production (day-of or day-prior)
- Boards composed in CTS kitchen
- Cheesecakes / desserts prepared
- Station ingredients prepped
- Quality check pre-transport

### Phase 4 — Transport
- Loaded to client venue
- Temperature-sensitive items handled separately
- Setup materials transported alongside food

### Phase 5 — Setup (on-site, if booked)
**Standard setup ($400)** — full montage, no theme.
**Premium themed setup ($600)** — themed montage matching aesthetic from client reference photos.

### Phase 6 — Service
**Drop-off** — items placed, brief client walkthrough, exit.
**Attended** — waiter ($25/hour) handles guest service through duration.
**Live station** — server prepares dessert live during the event (tiramisu, fondue, Dubai strawberry, etc.).

### Phase 7 — Breakdown
Crew returns to remove platters, clean station, recover props (themed setups).

### Phase 8 — Balance settled
50% balance due 24 hours **before** event. Post-event = client feedback + asset capture.

## What separates CTS delivery from generic catering

1. **Live element by default** — even non-station bookings get presentation-focused delivery.
2. **Themed customization tier** — most local caterers stop at "drop off the tray."
3. **Quote authority centralized** — Luis Torres owns quote integrity; sales staff can't freelance pricing.
4. **Cheese + meat board floor** (7 + 4) — every event hits a visual standard, not just "some food."

## Operational risks to manage

- **Last-minute scope creep** — handled by 1-week / 15-day rules.
- **Station availability** — pricing for several stations still pending; see [[01-Brands/Cheese-To-Share/01-Systems/Finance/Pricing-Logic|CTS Pricing Logic]].
- **Reference-photo expectation gap** — client sends elaborate references but books standard tier; manage by quoting on what's actually booked.
- **Day-of staff coordination** — staff rates ($25/hr) require pre-event scheduling.

## Quality standards

- Every board hits 7-cheese / 4-meat floor.
- Presentation matches reference category (standard vs. premium themed).
- Setup arrives on time per agreed call sheet.
- Live stations begin within event window agreed in advance.
- Breakdown leaves venue space as found.
