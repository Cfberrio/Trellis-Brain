## Resumen
Se pidió el módulo de asistencia con check-in QR y reglas de ausencias (Fase 3). Al 2 de octubre estaba construido: check-in por sesión con código rotativo cada 2 minutos y pase de 30 minutos (sin geolocalización), máximo 3 ausencias injustificadas por semestre, regla de día entre semana, verano no cuenta, alertas, cumplimiento de padres (Required/Invited según la lista de clase subida), los tres grupos de asistencia (74/66/5) y filtros. Quedan abiertos: un rol de voluntario con acceso limitado y el envío automático del reporte semanal por email.

## Descripción
Phase 3. Verified against the code Oct 2.

- [x] QR check-in per session with a **rotating code** (changes every 2 minutes; a scanned link must be opened within 2–4 minutes, then the phone has 30 minutes to finish the form, which covers early leavers and the 5-minute end-of-class check-in). **No geolocation** anywhere in the build.
- [x] Max 3 unexcused absences per semester, plus excused and make-up attendance
- [x] Weekday rule: attending Mon, Wed or Thu counts as that week's OCIA class
- [x] Summer classes never count as absences
- [x] Alerts when a candidate approaches the limit (on screen: dashboard tile, absence tracker, Follow-ups)
- [x] Parent compliance: any of the 4 nights (Mon, Wed, Thu, Spanish Tue) meets the week; "Required" when a child is in sacrament prep (from the uploaded class list, never guessed from grade), others "Invited". 106 parents / 126 children loaded.
- [x] Three attendance groups for adults receiving sacraments: registered & attending (74), registered & not attending (66), attending & not registered (5)
- [x] Filters: program, role (OCIA / parent / learner), term, session
- [ ] Volunteer role with limited access: volunteers currently have the same access as catechists
- [ ] Weekly automated report: the report is on screen with print and CSV; nothing is emailed automatically
