# Parish Stripe Setup and Registration Process

## Canonical Statement

- **process**: To set up parish registrations, create a Stripe account using an official parish email, select 'Nonprofit organization' as the business type, and 'Religious organizations' as the industry.
- **rule**: Never collect parish logins or bank details directly; access must be granted via a Stripe Team invite (Administrator role) to the designated Trellis email.
- **fact**: Catholic parishes often use the diocese's group tax exemption or the Official Catholic Directory listing for Stripe nonprofit verification instead of an individual IRS letter.
- **decision**: Registration pages for the parish will be standalone pages reached by QR code rather than built directly on the WordPress site.
