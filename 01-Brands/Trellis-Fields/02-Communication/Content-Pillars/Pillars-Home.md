## Purpose

4-pillar content system for Trellis Fields. Every piece of content should map to one pillar. Each pillar carries the structure `Hook → Situation → Development → Insight → Close` adapted to its own format identity.

## The 4 pillars

| # | Pillar | Protagonist | Format core |
|---|---|---|---|
| 1 | **Cultura del Equipo** | Team + culture | BTS, processes, dynamics, internal moments |
| 2 | **Educativo / Diagnóstico** | The problem | Brand-content diagnostics, motion graphics, Vox-style |
| 3 | **Storytelling** | Real story | Cases, brand journeys, dramatizations |
| 4 | **Trends de Agencias** | Viral format | Agency-life adaptations of viral trends |

> Note: Pilar "Anuncios" exists as 5th category in source ClickUp doc but is empty — deferred until ad strategy is authored.

## Structure shared across pillars

```
Hook → Situation base → Development → Insight / Tension → Close
```

What changes per pillar = **protagonist** + **tone**:

| Pillar | Protagonist | Tone |
|---|---|---|
| Cultura del Equipo | Team / culture | Observational, close, human |
| Educativo / Diagnóstico | The problem | Editorial, direct, sharp |
| Storytelling | Real story | Narrative, emotional, cinematic |
| Trends | The format itself | Light, fast, culturally tuned |

## Universal anchor

Trellis Fields message spine:

> **"Structure that makes your brand feel alive — and grow."**

Every pillar must reconnect back to this anchor — structure + humanity, method + emotion.

## Execution defaults (all pillars)

- Motion graphics / Vox-style explainer for diagnostic + educational
- AI used for specific visual elements (not the whole)
- Cinematic storytelling touch
- A-roll for talking-head + dramatized moments
- Animated subtitles
- Close, accessible language (lenguaje cercano)
- Distinct personality / characters when each team member appears (Charlize / Julián = editing universe; Cris = strategy / dev; etc.)

## Content series rules (from source meeting transcript)

**Series: Problemas de contenido**
- "El error que veo en marcas"
- "El error que mata el engagement"
- "El error que hace que tu contenido parezca publicidad"

**Series: No es el algoritmo**
- "No es el algoritmo, es tu contenido"
- "No es el algoritmo, es tu storytelling"
- "No es el algoritmo, es tu estrategia"

## Lead magnet logic (from source — Alex Hormozi alignment)

> "Tu contenido no es para resolver el problema completo. Es para resolver un problema pequeño y crear conciencia del problema grande."

Each pillar should:
1. Show a **small win / small problem solved**
2. Reveal the **larger problem** that the Skool community resolves
3. Drive to community capture (DM / link / Skool)

**Vehicle for the community = the pillars.** Not "join us" CTAs.

## Production cadence (minimum)

Per the TF STRATEGY weekly rhythm:
- 1 live implementation sprint (ship a deliverable)
- 1 teardown/critique session
- 1 template / workflow drop
- 3–5 short-form cuts repurposed from the above

Map each cut to a pillar before posting.
