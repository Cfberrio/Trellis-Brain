# Pillar 1 — The Hook

## Definition
The Hook is **the initial promise** of the content. Not "the first line". It's the **complete concept** that forces the viewer to stay for the resolution.

**Rule:** If the hook doesn't exist, the rest of the storytelling doesn't matter.

## What A Hook Must Achieve (in 1 line)
Make the viewer think: **"Ok… I need to see how this ends."**

## Trellis Hook Checklist (minimum structure)
A Trellis hook must include at least **one** of:
- **Pregunta quemante** ("¿Por qué nadie te dice esto?")
- **Dolor real** ("Esto es lo que te está frenando…")
- **Resultado deseado** ("Así se logra X en Y minutos")
- **Twist / contradicción** ("Esto suena bien, pero está mal…")
- **Prueba / credibilidad** ("Lo probamos y pasó esto…")
- **Identidad / pertenencia** ("Si eres de los que… esto es para ti")

## Hooks By Soil (which type to use per audience state)

| Soil | Hook type | Example |
|---|---|---|
| 1 — Desconocido | Curiosity + clarity | "Esto es lo que hacemos (sin que te des cuenta)" |
| 2 — Descubrimiento | Problem + revelation | "La mayoría piensa esto… y por eso falla" |
| 3 — Consideración | Objection + proof | "Si estás entre A y B, mira esto" |
| 4 — Primera compra | Safety + accompaniment | "Si es tu primera vez, haz esto primero" |
| 5 — Recurrente | Novelty + insider | "Lo nuevo que estamos probando esta semana…" |
| 6 — Comunidad | Belonging + participation | "Solo los de la casa entienden esto…" |

See [[Soils-Framework]] for full soil definitions.

## 3 Questions To Build A Hook
1. **What should the person feel in 1 second?** (curiosity / identification / urgency)
2. **What promise are we making and what resolution do we promise?** (what they'll get)
3. **What brake or objection do we break from the start?** ("y NO, no necesitas X…")

## Non-Negotiable Hook Rules
- Hook **cannot depend on knowing the brand** (except Soil 6).
- Avoid generic hooks like "Hoy te voy a enseñar…"
- Hook must be **understandable without context**.
- If the hook cannot be written in **one sentence**, it's not ready.

## Planning Mini-Template

```
Pillar 1 — Hook
- Soil: ___
- Emotion objective (1s): ___
- Promise / resolution: ___
- Objection we break: ___
- Hook line (1 sentence): ___
```

# Pillar 2 — Build Up

## Definition
The **Buildup** is the phase where we **emotionally and narratively prepare** the content so the **Value** can be received.

Not filler. Not decoration. It's **tension + context + connection**.

> If the **Value is the fruit**, the **Buildup** is the moment when you make someone **want to bite it**.

## What Buildup Does
Buildup is everything that happens **before** delivering the **core Value**. It exists to:
- Create **attention**
- Generate **curiosity**
- Activate an **emotional response**
- Prepare the **Audience** to receive a solution

If content starts delivering Value directly without Buildup:
- The message gets lost
- Engagement drops
- The content feels flat or "salesy"

## What Buildup Is NOT
- A long intro
- Unnecessary context
- Talking for talking's sake
- Empty hype

> Buildup does not exist without intention.

## Buildup's Single Function
> Align the audience's emotional state with the Value we're about to deliver.

Every Buildup must internally answer:
- What is this person feeling before they see the content?
- What tension can I activate without lying?
- What context do they need so the Value has impact?

## Types Of Buildup (used in planning, not as folders)

### Emotional Buildup
Leans on: frustration, desire, fatigue, expectation.
**Example:** show the problem before explaining the solution.

### Contextual Buildup
Leans on: briefly explain the scenario, show the "before", place the audience in a real situation.
**Example:** "Esto es lo que pasa cuando no tienes X."

### Explosive Buildup
Leans on: strong statements, contrasts, immediate tension.
**Example:** break a common belief.

### Observational Buildup
Leans on: real scenes, everyday moments, behind-the-scenes.
**Example:** show without explaining yet.

## Buildup Applied To Brands

| Brand | Buildup | Value | Effect |
|---|---|---|---|
| Discipline Rift | Kids warming up, gazes, mistakes, effort | Discipline, team, development | Buildup connects emotionally before teaching |
| Cheese to Share | Sharing, hands, laughter, waiting | Experience, connection, occasion | Product isn't sold — it's desired |
| Trellis | Chaos, disorder, content without structure | Clarity, system, intention | Audience recognizes themselves before learning |

## Buildup Workflow

### In planning
- Director defines the Buildup type
- Clear in the content brief

### In recording
- Capture moments that serve the Buildup
- Not everything is A-Roll
- Context matters

### In editing
- Editor builds the Buildup's rhythm
- Doesn't accelerate just to accelerate
- Respects narrative tension

## Buildup + Feedback Loop
Buildup **is also validated**, not assumed.

In the Feedback Loop:
- If audience doesn't stay → Buildup failed
- If message gets misinterpreted → Buildup confused
- If no connection → Buildup didn't align emotion

> Don't scale content with a broken Buildup. Editors **must return to analysis**. Directors and editors **analyze together**. Buildup adjusts before creating more content.

## Buildup Final Rule
If you can't explain:
- What emotion the Buildup activates
- How it prepares the Value
- Who it's designed for

Then it's not Buildup. It's improvisation.

# Pillar 3 — Value (Delivery)

## Definition
**Value is the fruit.**

This is the moment content **delivers something real** and justifies the audience's time.

> If here there's no clarity, relief, or transformation — content doesn't work, even with views.

## What Value Is
What the person **takes away** after consuming the content:
- Alleviates a **real pain**
- Resolves a **specific tension**
- Provides **practical clarity**
- Helps **decide, understand, or act**

## What Value Is NOT
- Generic inspiration
- Opinion without application
- "Good content" without utility

> If it can't be applied, understood, or felt clearly — there's no Value.

## Delivery Vehicles
Value doesn't live only in the message. It lives in **how we deliver it**. TF uses these vehicles intentionally:

| Vehicle | Use for |
|---|---|
| **Short-form video** | Quick clarity, real examples, micro-frameworks |
| **Email / Newsletter** | Depth, better explanation, Value validation |
| **Live / Webinars** | Teach, answer questions, demonstrate expertise in real time |
| **Interactive content** (quizzes, diagnostics, tools) | Help the person identify their problem themselves |
| **Communities** (Slack, Discord, IG Close Friends, etc.) | Reinforce Value in Soils 5–6: depth, belonging, co-creation |

Not all content uses all vehicles. **Choose the one that best delivers the defined Value.**

## Delivery Rule (mandatory)
Before producing, someone on the team must answer:
- What exact Value is being delivered?
- What pain is alleviated?
- What can be understood or done afterward?
- Is this format the best vehicle for that Value?

If no clear answer → adjust before recording or editing.

## Value Shape By Soil

| Soil | Value Shape |
|---|---|
| 1–2 | Clarity + curiosity. Brief, simple, no overload. |
| 3 | Explanation + comparison + structure. |
| 4 | Validation + risk reduction. |
| 5 | Depth + novelty + recognition. |
| 6 | Belonging + participation + identity. |

Value misplaced = Value lost.

## Value + Feedback Loop
Value is **not assumed**. It's **validated**.

After publishing:
- Did people understand?
- Did they comment?
- Did they apply it?
- Did they ask for more?

If Value didn't land:
- Editors return to analysis
- Director reviews the focus
- Adjust the delivery or the focus
- **Don't create more content until you fix it**

> Scaling without validating = repeating errors.

## Value Final Rule
If you can't explain:
- What Value you're delivering
- What pain you're alleviating
- For whom
- In what Soil

Then you're not creating with intention. You're improvising.

> In Trellis: **Value is the fruit.**
