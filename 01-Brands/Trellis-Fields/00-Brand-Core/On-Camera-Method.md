## Purpose
Standardize **how the team speaks on camera** so messages sound clear, secure, and conversational (not lecture-read). Adapted from Alex Hormozi's framework.

## Rule #1 — Sin Script No Hay Autoridad
- **Always have a script**, even if short.
- Improvising → sounds reactive. With script → sounds intentional.
- Goal: the team can repeat a piece with **consistency** — same idea, same rhythm, same intention.

### Minimum script structure (15–45s)
1. **Hook** (1 line)
2. **Problema / tensión** (1–2 lines)
3. **Insight** (1 line: "aquí está lo que nadie ve")
4. **Solución / estándar Trellis** (1–2 lines)
5. **Prueba** (micro proof: data, process, "lo mostramos")
6. **CTA** (1 line)

## Sales Tone — 3 Constants (Non-Negotiable)

These 3 maximize comprehension + automatically project clarity/authority:

### A. Volumen suficiente
- Speak loud enough to be understood without effort
- "Confianza" is often just: **sube el volumen**

### B. Velocidad correcta
- Too fast → drops confidence
- Too slow → sounds insecure / clunky
- **Range: 135–185 palabras por minuto**

### C. Articulación (dicción)
- Round words, don't bite endings
- No mumbles, no "entre dientes"
- Articulating well naturally slows you when nervous

## 2 Presence Variables (write in the script)

Authority ≠ shouting / acting. Authority = **control**.

### A. Pausas
- **Short pause** = emphasize / "mark the point"
- **Long pause** = "your turn / process / respond"
- Well-used pauses = signal of competence

### B. Entonación
- **Subir** at end = question / inviting response
- **Bajar** = affirmation / cierre
- Authority = afirmas con caída; pregunta only when you want interaction

### How to notate in script
- `...` = short pause
- `.` = stop completo
- `?` = voz arriba (pregunta / cliente's turn)

## How To Sound Natural (without sounding "read")

Naturality is NOT improvising. It's **memorizing until you can breathe the script**.

### Trellis Memorization Method (fast)
1. Print/duplicate the script (or 2 versions on screen)
2. Read aloud, **perfectly articulated**
3. Then **erase 1 word**
4. Read again with that word missing
5. Repeat erasing one word at a time… until you can say it looking at "almost empty" screen

**Result:** you no longer "recite" — you **inhabit** the message.

## 3 Templates (Clarity + Authority)

### Template A — "Regla / Estándar" (15–25s)
- **Hook:** "Regla Trellis: ____."
- **Contexto:** "La mayoría hace ____."
- **Verdad:** "Eso genera ____."
- **Fix:** "Haz ____ (1 cosa)."
- **Proof:** "Mira esto / así se ve."
- **CTA:** "Si quieres ____ comenta ____ / escríbenos."

### Template B — "Problema → Diagnóstico → Solución" (25–45s)
- **Hook:** "Si te pasa ____ esto es por ____."
- **Diagnóstico:** "Se ve así: ____."
- **Solución:** "La corrección real es: ____."
- **Mini demo:** (b-roll / ejemplo rápido)
- **Cierre:** "Guárdalo / compártelo / agenda / regístrate."

### Template C — "Historia corta con autoridad" (30–60s)
- **Hook:** "Hoy pasó algo que explica ____."
- **Escena:** (1 detalle visual)
- **Lección:** "Esto demuestra ____."
- **Estándar:** "En Trellis hacemos ____."
- **CTA:** "Si estás en ____ te sirve ____."

## Camera Checklist (what matters)

### Antes de grabar (30 sec)
- 1 frase: **qué quiero que la gente entienda**
- 1 frase: **qué quiero que hagan**
- Mark script with `...` and `?`

### Durante
- **Mirada:** lente, not screen
- **Postura:** pecho abierto, quietud (few hand gestures, intentional)
- **Ritmo:** start slightly slower than feels "natural"
- **Pausas:** no fillers ("ehh/este")

### Después
- If can't understand without context in 3 seconds → **rehacer hook**

## Trellis Authority Rules (no vendehumo)
- Authority = **estándares + precisión**, not grandiosity
- ❌ Never: "somos los mejores"
- ✅ Sí: "esta es la regla", "este es el criterio", "así se ve bien vs mal"
- CTA must be **simple** (1 action)

## Role Delivery Rules

### Editor
- Priority: visual clarity of the point (on-screen text + b-roll that proves the claim)
- Cuts: eliminate filler before the first strong point

### Director / Founder
- Priority: **estándar + decisión** (talk less, pause more)
- Where control matters most: **the invitation / CTA** (say the question, then shut up)

## Universal Trellis Mini-Script (copy/paste)

> **Hook:** "Te voy a decir esto una sola vez: ____."
>
> **Problema:** "Si estás haciendo ____ te está pasando ____."
>
> **Verdad:** "No es falta de ganas… es ____."
>
> **Regla Trellis:** "La regla es: ____."
>
> **Demo:** "Mira esto… (____)"
>
> **CTA:** "Si quieres que te lo mande aplicado a tu caso, comenta '____'."
