## 1. PROBLEMAS DE MARCA / CONTENIDO

| Problem | Solution |
|---|---|
| Publican sin sistema → dependen de inspiración | Framework de storytelling basado en problemas reales + SOPs simples de producción |
| No saben traducir su experiencia en contenido educativo | Librería de hooks probados + framework de storytelling + plantillas reutilizables |
| Tienen identidad visual pero sin narrativa profunda | Content OS — pilares + formatos + definición de calidad |
| Producen mucho contenido pero no construyen autoridad | Framework "Problema → Diagnóstico → Solución → Ejecución" |
| Falta consistencia porque el proceso no está documentado | SOPs simples + checklist de QC por formato |
| Equipos pequeños sin pipeline de producción claro | Pipeline ClickUp → producción → publicación + brief en 5 minutos |
| Fundadores que cargan toda la estrategia solos | Plantillas reutilizables + Content OS + sistema de revisión estructurada |
| "No sé qué vendemos exactamente" | Oferta productizada + propuesta template + definición clara de oferta |
| La marca se siente "bonita" pero no se entiende el valor | Framework de storytelling + Content OS + definición de valor y diferenciadores |
| No tienen una "opinión" (suena genérico) | Framework de opinión + pilares de contenido + guía de estilo |
| Hablan de tips pero no de decisiones | Behind the scenes de decisiones reales + estudios de caso reales |
| No saben convertir resultados en historias | Framework de storytelling + case studies empaquetados |
| No tienen "pilares" que conecten todo | Content OS — pilares + formatos conectados |

## 2. PROBLEMAS DE EQUIPO / OPERACIÓN

| Problem | Solution |

| Pérdida de tiempo en tareas repetitivas | Automatizaciones realistas + checklist automático por tipo de contenido |
| Falta de estándares de edición y storytelling | Guía de estilo + checklist de QC por formato |
| Dificultad para escalar sin contratar más | Procesos sistematizados y reutilizables + pipeline eficiente |

| No hay pre-producción (todo se decide en edición) | Brief en 5 minutos + pre-producción con checklist |

| El editor adivina intención (briefs pobres) | Brief en 5 minutos + plantillas claras |
| El director revisa 3 veces lo mismo | Sistema de revisión en 2 rondas máximo + checklist de QC |
| No hay control de calidad (errores narrativa, pacing, audio) | Checklist de QC por formato + guía de estilo |
| Reels que se ven bien pero no retienen | Framework de storytelling + guía de ritmo y edición |

## 4. PROBLEMAS DE COMUNIDAD (SKOOL)

## Solutions Catalog — What Trellis Actually Can Deliver

### Sistema Trellis (contenido base)
- Framework de storytelling basado en problemas reales
- SOPs simples de producción de contenido
- Librería de hooks probados
- Sistema de revisión estructurada
- Plantillas reutilizables de edición
- **Content OS** (1 página): pilares + formatos + cadencia + definición de calidad
- **Brief en 5 minutos** (formulario simple)
- **Guía de estilo**: ritmo, cortes, audio, captions, marca, templates
- **Checklist de QC por formato** (Reel, carrusel, YouTube, anuncio)
- **B-roll bank + Asset library**
- **Framework "Problema → Diagnóstico → Solución → Ejecución"** (sello TF)

### Automatización Realista
- Brief generator con GPT
- Checklist automático por tipo de contenido
- Naming system de archivos
- Pipeline ClickUp → producción → publicación
- Repositorio central de assets
- **Weekly Sprint (60 min)** lunes
- **Daily async (5 min)**
- **Sistema de revisión en 2 rondas máximo**
- **Definition of Done** por pieza
- **Plantillas de feedback** (emociones fuera, criterios dentro)

### Para Comunidad (Skool futuro)
- Breakdown real de procesos internos
- Errores que cometieron como equipo pequeño
- Frameworks accionables (no teoría)
- Behind the scenes de decisiones reales
- Estudios de caso reales (sin hype)
- **Oferta productizada** (1-2, no 10 servicios) — ejemplo: "Trellis Content Engine: 30 días de producción + sistema"
- **Producto de entrada** (low ticket o trial) — ejemplo: auditoría + roadmap + 7 días de implementación
- **Case studies empaquetados** (antes / después / decisiones / proceso / métricas)
- **Pipeline mínimo de leads** (lead magnet + secuencia + call script + propuesta template)
- **Rutas por nivel:**
  - Starter: orden + consistencia
  - Builder: sistema + oferta
  - Operator: equipo + escalado
- **Biblioteca de templates descargables**
- **Rituales:**
  - 1 sesión semanal (oficina abierta)
  - 1 reto mensual (implementar una pieza del sistema)
  - 1 hot seat quincenal (caso real de un miembro)
- **Tablero de progreso** (checklist por semana)

## Operating Constraint
Nada que requiera equipos grandes ni infraestructuras complejas. TF solves at the level a small founder-led team can actually implement.
