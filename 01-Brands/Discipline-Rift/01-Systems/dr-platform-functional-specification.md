# DR Platform Functional Specification

## Canonical Statement

- **process**: The registration process follows a 7-step linear flow: Search school/team, Select team (with real-time capacity check), OTP Login, Parent/Child data entry, Review, Stripe Payment, and Confirmation.
- **rule**: Parent access uses a passwordless OTP (One-Time Password) system via email; codes expire in 10 minutes. Admin access uses traditional email/password credentials.
- **fact**: The Parent Dashboard tracks child progress through 'Tiers' and 'Skills' with visual status indicators: Consistent (mastered), In Development, or Locked.
- **process**: Automated communication includes daily 7:00 PM ET pending message alerts and 8:30 PM ET season start reminders (30 days out).
- **preference**: The platform uses a 'Mobile First' design philosophy with sport-specific color coding: Volleyball (Green), Tennis (Yellow), and Padel/Pickleball (Orange).
