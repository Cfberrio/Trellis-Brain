## Purpose
Director's playbook for creating video ads targeting parents at **Soil 1 + Soil 2** (cold audience: don't know our brand, sports, costs, logistics). The ad's job: 1–3 sec attention → parent language → recognizable problem → concrete + credible solution → simple CTA that unlocks details.

> Think: **clarity + emotion + confidence** in under 60 seconds.

## Context: Soil 1 + 2 Audience
- Don't know us
- Don't know our sports
- Don't know logistics
- Don't know costs

The ad doesn't explain everything (that lives on the website). The ad must:
1. Capture attention in 1–3 sec
2. Speak like a parent speaks
3. Present a recognizable problem
4. Deliver a concrete + credible solution
5. Ask a simple action (CTA) that unlocks details immediately

## 1. The 6 Non-Negotiable Rules (every script must pass)

### Rule 1 — Direct Address (from line 1)
Must speak to someone from second 1. Audience = parents → first line includes **"Parents" / "Hey parents"**.

- ✅ "Parents, después de la escuela es cuando las pantallas normalmente se apoderan."
- ❌ "Después de la escuela es donde empieza el screen time…" *(floating context)*

### Rule 2 — Plain Language (Parent Language, not Planner/Workshop)
Avoid presentation words: "unstructured time", "default", "spikes". Parents must think: *"yes, that happens in my house."*

**Translations to parent vocabulary:**

| ❌ Planner | ✅ Parent |
|---|---|
| unstructured time | tiempo libre / nada planeado / tiempo improductivo |
| default | lo que suele pasar |
| spikes | se dispara / se apodera / sube rápido |

> Many parents talk about **productividad** ("quiero que mi hijo aproveche la tarde"), so "tiempo improductivo" connects better than "unstructured."

### Rule 3 — Compressed Problem (1–2 beats, no repetition)
Ads have no time for repetition.

- ✅ "Se hace la tarea… y después las pantallas se apoderan."
- ✅ "Sales de la escuela, llegas a casa… y se pierde la tarde."
- ❌ "Tarea… luego pantallas. O pantallas primero… luego más pantallas…" *(redundant)*

### Rule 4 — Accuracy (simple but true claims)
**Approved (simple + true):**
- "Enseñamos los fundamentos paso a paso."
- "Construimos habilidades y carácter."
- "Coaches guían el progreso desde cero, sin presión de club."
- "Damos un enfoque claro cada sesión y construimos sobre eso."

**Not approved:**
- ❌ "We teach one simple skill."

### Rule 5 — Promise Delivery (if "we fix that", deliver the fix immediately)
"We fix that" works only when the next line answers **How / When / Where**.

- ✅ "We fix that. Justo después de la escuela, en el campus, con sesiones deportivas guiadas por coaches desde que suena la campana."

### Rule 6 — Specific CTA (action + immediate value)
"Comment 'SPRING' and we'll send details" is not enough. CTA must say **exactly what they receive now + why it helps**.

- ✅ "Comment 'SPRING' y te mandamos: (1) si tu escuela está incluida, (2) el día/horario, y (3) qué hace un principiante en la primera semana."

## 2. Workflow With Rebekah (mandatory)

**Rebekah** = writing intern. Critical for making language sound like a real parent.

### Roles
- **Director:** protects strategic integrity (structure, beats, promise, offer clarity, truth claims)
- **Rebekah:** adjusts rhetoric + language (parent tone, ritmo, simplification, correct words)

### Flow (mandatory)
1. Director writes draft (structure + strategy)
2. Director passes the **Ads Check** (Section 7)
3. Rebekah reviews (parent language + clarity)
4. Director re-validates **Accuracy** + structure (text changes can break claims)

Rebekah translation example:
- ❌ "unstructured time" → ✅ "tiempo improductivo" / "nada planeado"

## 3. Standard Script Structure (DR Template)

**Duration:** 20–35s (up to 45s if visual carries weight)

### Beat Map
| Beat | Time | Element |
|---|---|---|
| 1 | 0–2s | Hook with **Direct Address** |
| 2 | 2–6s | Problem in **Compressed Problem** |
| 3 | 6–8s | "We fix that" |
| 4 | 8–14s | **Promise Delivery** (How/When/Where) |
| 5 | 14–24s | Resultado / prueba |
| 6 | 24–35s | Urgencia + **Specific CTA** |

### Proof (observable + believable — PDF "week one you see it"):
- "En la primera semana se nota: más movimiento, más enfoque, más ganas de volver."
- "Niños tímidos empiezan a pedir la pelota."
- "Fallan, se ríen, reinician y lo intentan otra vez."
- "Terminan sonriendo y diciendo '¿puedo hacerlo otra vez?'"

## 4. Reel Templates (use as angle bank, not literal scripts)

### Reel 01 — Pantallas después de la escuela
**Idea:** después de la escuela, las pantallas se apoderan porque no hay una opción fácil.
- Change planner words → Plain Language
- Reduce to Compressed Problem
- Correct claims (no "one skill") → Accuracy
- If "we fix that" → deliver Promise immediately

### Reel 02 — Principiantes / miedo a ser malo
**Idea:** muchos niños evitan deportes por miedo a equivocarse / sentirse juzgados.
- Mantén emoción (vergüenza / inseguridad)
- Promete ambiente seguro + coaches + progreso desde cero
- Proof visual: tímido → participando

### Reel 03 — La confianza se construye a propósito
**Idea:** no dejan el deporte por el deporte; lo dejan por cómo se siente.
- Visualiza experiencia: "fallar → reír → reset → intentar"
- Enfatiza apoyo + repetición (sin presión)

### Reel 04 — La victoria real es que quieran volver
**Idea:** si no quieren regresar, no hay progreso.
- Enfatiza diversión + consistencia
- Beneficio padres: encaja en la semana (sin vida de club)

### Reel 05 — Reset de Spring / no club pressure
**Idea:** alternativa real después de la escuela sin fines de semana tomados.
- Mantén diferenciadores ("no weekend takeovers")
- Conecta con rutina nueva / reinicio
- Urgencia: escuelas cierran calendarios temprano

## 5. Planner → Parent Translation Checklist

Use before passing to Rebekah:

| Planner | Parent |
|---|---|
| unstructured time | "nada planeado" / "tiempo improductivo" |
| default | "lo que suele pasar" |
| spikes | "se apodera" / "sube rápido" |
| structure | "rutina" / "algo mejor que hacer" |
| coached play | "juego guiado por coaches" |
| fundamentals | "fundamentos" / "bases" |

## 6. CTA Library (one per ad — never mix)

### Option A — Comment (high intent)
> "Comment 'SPRING' y te mandamos ahora mismo:
> 1. si tu escuela está incluida,
> 2. el día y horario,
> 3. cómo funciona para principiantes (qué hacen cada semana)."

### Option B — Click (low friction)
> "Tap el link para ver si tu escuela está incluida, el horario, y registrarte."

## 7. NEW ADS CHECK (mandatory before approval)

Every script must:
- [ ] Line 1 with **Direct Address** ("Parents…")
- [ ] Parent language: **Plain Language** (no planner/workshop words)
- [ ] Problem in 1–2 beats: **Compressed Problem**
- [ ] True claims: **Accuracy** (no "one skill")
- [ ] "We fix that" followed by How/When/Where: **Promise Delivery**
- [ ] CTA with immediate value: **Specific CTA**
- [ ] Final review by Rebekah

If any fails → return to rewrite.

## 8. Visual Guide (B-roll / A-roll / subtitles)

### B-roll (most powerful)
Emotional before/after visual proof:
- High fives, risas, movimiento, energía
- Coaches enseñando (real learning moment)
- Juego guiado + compañerismo
- Cierre con sonrisas (signal: "I want to come back")

### A-roll (if used)
Recognition-triggering:
- Niños pegados a pantallas, cara plana, aislados
- Contraste inmediato con deporte + amigos + movimiento

### Subtitles + effects
- Subtitles always (many viewers no audio)
- Dynamic: highlight key words ("Parents", "after school", "we fix that", "on campus", "week one", "SPRING")

## Standard Rule
> This playbook is not a suggestion. It's the **minimum standard** of clarity, honesty, and performance for parent ads.
