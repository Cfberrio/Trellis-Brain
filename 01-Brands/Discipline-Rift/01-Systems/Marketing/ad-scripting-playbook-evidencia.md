# Ad Scripting Playbook — Evidencia

## Canonical Statement

- **rule**: Ad scripts for the license program must avoid 'skepticism triggers' like 'passive income', 'financial freedom', 'franchise', or 'investment opportunity'; use 'license', 'operator', and 'playbook' instead.
- **process**: The standard ad script rhythm for cold audiences follows a 50-second structure: Hook (0-3s), Bridge (3-8s), Authority/Credibility (8-15s), Opportunity/Outcome (15-26s), What they gain (26-38s), Risk reduction (38-44s), and a 20-second lead magnet CTA (44-50s).
- **rule**: Ad copy should assume 'zero context': never start with the program name; start with a problem the audience recognizes and define 'license' in one line.
- **rule**: CTAs must be frictionless: 'Drop your name + number + sport experience—takes 20 seconds. We’ll text you the next step.'
