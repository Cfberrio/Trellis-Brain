# DR Marketing Execution Standards

## Canonical Statement

- **rule**: Creative testing must prioritize first-party funnel progression (e.g., team selection rate) over Meta-reported CTR or CPC, as these are diagnostic while progression is a business outcome.
- **rule**: Creative decisions should not be based on low-spend data (insufficient evidence); maintain a control creative and use controlled tests to isolate specific variables (e.g., message framing vs. video format).
- **rule**: Attribution must be reconciled against first-party data; Meta-reported ROAS (especially view-through) is not a proxy for incremental revenue.
- **rule**: Operational discipline requires avoiding constant ad toggling; maintain stable data windows to allow for meaningful analysis.
