# Parent Message Notification Workflow

## Canonical Statement

- **process**: The 'Parent New Messages' workflow triggers an hourly notification if a coach message remains unopened by a parent.
- **fact**: The Parent Dashboard is the primary channel for coaches to communicate schedule changes, equipment requirements, and student progress updates.
- **rule**: Parent notification emails for new messages must include the coach's name, team name, unread count, and a preview of the latest message.
