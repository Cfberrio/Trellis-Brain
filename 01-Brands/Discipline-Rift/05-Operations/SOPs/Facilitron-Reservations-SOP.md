# Facilitron Reservations SOP

## Purpose
Submit facility reservations to secure dates + locations for DR teams throughout the season. This ensures teams have guaranteed access to spaces for practices and games, based on the Google Sheet schedule.

> Once reservations are submitted, wait for faculty approval before proceeding.

## Step-By-Step

### 1. Access the schedule
Open the Google Sheet containing team schedules. Identify the specific dates and times needed for each team for the entire season.

### 2. Log in to Facilitron
Go to the Facilitron website and log in. Navigate to the appropriate county and school using the lookup feature.

### 3. Search for the facility
Enter the school name and select the correct location (e.g., outdoor basketball courts). If the address is missing, use the information from your database or the Google Sheet.

### 4. Select dates and times
Using the schedule, input the required dates and times for the reservation. Set up recurring bookings if the team meets weekly or on a regular basis.

### 5. Enter reservation details
Fill in all required information: event type (e.g., Volleyball Program), payment method, insurance details. Use the non-profit status if applicable for reduced pricing.

### 6. Submit the reservation
Review all details and submit the reservation request. If the primary payment method fails, use an alternative and notify the accounting team.

### 7. Wait for approval
After submission, monitor the status of the reservation. Faculty or school admins will review and approve (or deny) the request. Follow up if needed.

## Payment Methods
- **Card 4457** — primary
- **DR card** — alternate; if used, notify accounting so books are updated

## Handling Missing Or Incorrect Information

| Situation | Action |
|---|---|
| Missing addresses | Paste into database when found |
| Basketball courts unavailable | Book alternative (e.g., parking lot) and request a change in the comments |
| Time slot unavailable | Book closest available and add a comment requesting actual desired time |
| Insurance required | Select in-house insurance |

## Why We Do This
Submitting reservations ensures teams have necessary spaces reserved, prevents scheduling conflicts, and provides official documentation for school and county records. This organized process supports smooth operations for all teams throughout the season.

## Follow-Up
After submission, follow up with the admin for approval or denial. Update Facilitron Status field in [[01-Brands/Discipline-Rift/01-Systems/Sales/GHL-CRM-Pipeline-Spec|GHL]]: `Not Started` → `Submitted` → `Approved` / `Denied` / `Pending School Response`.
