# Facilitron Facility Reservation Process

## Canonical Statement

- **process**: Facility reservations are submitted via Facilitron to secure dates and locations for teams based on the Google Sheet schedule, requiring faculty approval before proceeding.
- **rule**: When booking, use non-profit status if applicable for reduced pricing and enter specific event details like 'Volleyball Program'.
- **rule**: If a primary payment method fails, use an alternative (e.g., DR card) and immediately notify the accounting team.
- **rule**: If specific facilities like basketball courts are unavailable, book an alternative (e.g., parking lot) and request a change in the reservation comments.
