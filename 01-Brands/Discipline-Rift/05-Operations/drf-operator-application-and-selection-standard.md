# DRF Operator Application and Selection Standard

## Canonical Statement

- **process**: The DRF Operator application uses a 15-question 'swipe' assessment to measure initiative, ownership instinct, outreach comfort, operational stamina, and leadership maturity.
- **rule**: DRF Operator fit is scored on a 10-point scale based on 'best-fit' directions: 8–10 is a strong fit, 6–7 is a possible fit, 4–5 suggests a coach/intern path, and 0–3 is a low fit.
- **fact**: The application includes short-answer questions focusing on sports experience, reliability under pressure, interest in local growth/leadership, and ability to work within defined systems.
