## Strategic role
Pickleball is an active DR sport and it fills. Until the 2026-08-11 Notion pull this folder was an empty placeholder — DR itself never provided pickleball PDFs, so unlike tennis there is no internal `Source-Docs/` layer. Two layers now exist:

1. **[[01-Brands/Discipline-Rift/05-Operations/Training/By-Sport/Pickleball/Notion-Wiki/Notion-Wiki-Home|Notion Wiki]]** — DR's own coach curriculum, mirrored from Notion. Source of truth for what coaches deliver.
2. **[[01-Brands/Discipline-Rift/05-Operations/Training/By-Sport/Pickleball/Reference-Books/Kitchen-Library-Home|Kitchen Library]]** — 22 external sources (federations, PE publishers, donor racket sports) imported as full text on 2026-09-22 from The Kitchen Library research report. Not DR material: raw source input for building the missing half of the season.

## Canonical source (until 2026-09-11 — now historical, see banner above)
[[01-Brands/Discipline-Rift/05-Operations/Training/By-Sport/Pickleball/Notion-Wiki/Notion-Wiki-Home|Notion Wiki Home]] — start there. It mirrors the DR PICKLEBALL Notion database and is the source of truth for pickleball coaching material.

**The season is half-built.** The 6-week map is defined, but only Weeks 1–3 exist as sessions in Notion. Weeks 4 (Serves), 5 (Drop shots), and 6 (Rallying + Assessment) have no content at all. If pickleball is sold as a six-week season, coaches are improvising the back half.

## How to use this library
Use [[01-Brands/Discipline-Rift/05-Operations/Training/By-Sport/Pickleball/Notion-Wiki/Notion-Wiki-Home|Notion Wiki Home]] and the `Notion-Wiki/Curriculum/` sessions for coaching and AI context — that is what coaches run today, and there is no superseded DR source layer behind it.

For **building** the missing Weeks 4-6, or any K-5 material, go to [[01-Brands/Discipline-Rift/05-Operations/Training/By-Sport/Pickleball/Reference-Books/Kitchen-Library-Home|Kitchen Library Home]]. It is research input, not DR doctrine: never hand a Kitchen Library extract to a coach as-is, and verify any figure or activity name against the original source before it enters a DR document.
