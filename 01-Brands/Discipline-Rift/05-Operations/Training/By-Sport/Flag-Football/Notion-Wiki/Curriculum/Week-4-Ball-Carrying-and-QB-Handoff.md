# Week 4 — Ball Carrying + QB Handoff

**Theme:** Ball Carrying + YAC Chase **with QB→RB handoff after the whistle**
**Anchor activities:** YAC; Snake Run
**Cue of the week (protect working memory):** **"Tuck + lock it away."**
**Effort norm of the day:** "Reset fast" (jog back, eyes on coach, ready stance)

---

## Block 1 — Culture Routine + Belonging (3 min)

**Learning Target:** after the whistle, we can hand off cleanly and run with secure ball carry.

**Coach script (20–40s):** "Today we're learning how to **start fast after the whistle**: QB hands it, RB runs it — secure. Our cue is **tuck + lock it away**. Effort norm: **reset fast** so everyone gets reps."

**Micro-CFU (10s):** choral response — "What's the cue?" → **"Tuck + lock it away!"** Quick scan: who answers loud + ready stance.

---

## Block 2 — Retrieval Warm-Up (7 min)

**Learning Target:** retrieve last week's YAC habits — **catch → run hard → protect the ball**.

**Activity: Music-Stop YAC Chase**
- Pairs with a ball. Light toss/catch while music plays.
- When music stops + whistle: **ball carrier tucks + locks and sprints** to a cone line; partner chases (15–20s).

**Beginner version:** straight run, big space. **Experienced version:** must "show lock" on the first 2 steps (coach is watching).

**Micro-CFU (10s "Freeze"):** whistle → everyone freezes mid-carry. Coach scans for **4 points of contact** (hand, forearm, bicep, chest). One fast fix cue only: "Lock it away."

---

## Block 3 — Teaching Block (8 min)

**Learning Target:** install the handoff start — **whistle → handoff → tuck/lock → run downhill.**

**Demo (60–90s, then reps):**
- **QB job (no extra cue — just job description):** "Two hands, place it in the belly" (firm, not tossed)
- **RB job (tie back to cue):** receive → **tuck + lock it away immediately** → eyes up → run straight

**Blocked Practice (6 min):** groups of 3 in a lane — **QB + RB + "shadow" defender** (walk pace, no pulls). Rep starts **only on whistle**. QB hands off. RB runs 8–10 yards.

**Micro-CFU (15s):** "Show me the cue on step 2." Exit criterion to move on: **8/10 reps** = clean exchange + secure carry by step 2.

---

## Block 4 — Skill Acquisition Reps Engine (12 min)

**Learning Target:** get **volume + confidence** on handoff → secure run.

**Activity: Handoff Snake Run Lanes** (blocked → serial). Set 4–6 snake lanes with cones.

**Tier System (same drill, different demand):**
- **Tier 1 (Blocked):** whistle → handoff → run the snake, no defender
- **Tier 3 (Serial):** whistle → handoff → run snake → finish through a "gate" cone
- **Tier 5 (Constraint):** whistle → handoff → run snake while keeping ball **outside arm** when turning (advanced only)

**Rotation:** 3 reps RB then swap (QB↔RB). Keep lines short (2–3 kids per lane max).

**Micro-CFU (20s):** "Name the cue + show one rep." Listen for **"Tuck + lock it away."** Then immediate demo rep.

---

## Block 5 — Teaching Acquisition (Guided decisions) (12 min)

**Learning Target:** See → Decide → Act under light pressure — **protect the ball while a defender closes.**

**Activity: Handoff + Chase Read.** Same lanes, now add a defender behind RB.
1. **Shadow (walk):** defender follows — RB must keep secure carry.
2. **Chase (game pace):** defender tries to pull flag after 2 steps.

**Advanced read (only if they're ready):** "If defender is closing on your ball side, **switch to outside arm** *without losing tuck/lock*."

**Coach teaching moves (fast):** Perception Q — "What did you notice about where the defender was?" Replay immediately — "Now choose the outside arm and lock it."

**Micro-CFU (10s):** athlete answers + points: "Defender was on my right, so I switched to left (outside) and locked it."

---

## Block 6 — Application: Constraint Game (15 min)

**Learning Target:** transfer to a game — **whistle start + handoff + YAC finish with secure carry.**

**Constraint Game: YAC Points (4v4) — handoff required**
- **Rule:** every play begins on whistle with a **QB→RB handoff** (no passes this game)
- **Field:** short width, 10–20 yards to end zone
- **Scoring:** **1 point** if runner crosses goal line · **+1 "Security Bonus"** if runner maintains **tuck + lock** the whole run (coach decides fast)

**Coach focus:** praise the process — "You locked it away through contact — point!"

**Micro-CFU between rounds (10s):** "See → Decide → Act in one sentence." Example: "I saw the defender close left, decided to switch outside, and ran."

**Gamify (Week 4) — Ball Security Shield:** random whistle during game — everyone freezes and shows **tuck + lock** in under 2 seconds. Team earns the shield when **every player** nails it.

---

## Block 7 — Debrief + Exit Criteria + Spacing (3 min)

**Meaning tie (10–15s):** "Discipline is doing the right thing fast — **secure carry every time**, even when excited."

**Retrieval question (from memory):** "What's the cue?" → "**Tuck + lock it away.**" · "What starts every run today?" → "**Whistle → handoff.**"

**Exit Criteria (observable "learned"):** handoff is clean (no drops) AND RB shows secure carry by step 2 AND runner finishes through the line (doesn't stop early).

**Spaced practice preview:** "Next week we'll start warm-up with **2 whistle handoffs** before anything else."
