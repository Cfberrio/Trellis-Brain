# ZONES GAME — Field Awareness, Scoring Structure & Situational Intelligence

## 1. Field Overview (Complete Zone Structure)
Walk players through the field from an overhead perspective before beginning. Use consistent numbering every practice.

### Zone 1 — End Zones
**Purpose:** Touchdowns. Ball must cross into this zone to score. Both ends of the field are Zone 1.

### Zone 2 — Goal-Line No-Run Zones
**Purpose:** Must Pass. Located just outside each end zone. If the ball is spotted in this zone: you cannot run, you must pass. Always active when the ball is placed there.

### Zone 3 — One-Point Try Line
**Purpose:** 1-Point Conversion. Ball is placed on the far edge of the goal-line no-run zone. Must pass. Cannot run.

### Zone 4 — Two-Point Try Line
**Purpose:** 2-Point Conversion. Located 5 yards behind the 1-point line. You may run or pass.

**Field order facing the end zone:** Two-Point Line → One-Point Line → No-Run Zone → End Zone. That logic stays consistent.

### Zone 5 — Middle No-Run Zone (Grades 4–5 only)
Applies primarily to 4th & 5th grade. 2nd & 3rd graders can still learn it conceptually.

- **Location:** 10 yards wide total; extends 5 yards on either side of midfield (the 50-yard line).
- **Purpose:**
  1. Functions as a no-run zone **only if the ball is spotted inside it.**
  2. Contains the first down line (midfield).
  3. You must cross midfield to earn a first down.
- **Clarification:** works exactly like the goal-line no-run zones **when the ball is placed inside it.** If the ball starts inside Zone 5 → must pass. You cannot run the ball out of that zone. If you receive a handoff outside and run through it → it does not activate.
- **Only difference from other no-run zones:** it includes the first down marker.

### Additional Field Terms (Coach Reference)
- **Open Field Area** — space between no-run zones; normal run or pass allowed.
- **First Down Line** — located at midfield; must cross to reset downs.

## 2. Lesson Objective
Players will:
1. Identify each zone by number and function.
2. Move quickly to the correct zone when called.
3. Explain what is allowed in that zone.
4. Connect field position to scoring and first down decisions.

## 3. How to Run the Game

### Phase 1 — Recognition Speed
Coach calls: "ZONE 5!" Players sprint and touch the correct line within 5 seconds.
Out if: wrong zone, or too slow. Cue: "Sprint first."

### Phase 2 — Add Rule Understanding
After players arrive, ask: "What happens here?"
Expected answers:
- Zone 1 → "Touchdown."
- Zone 2 → "Must pass."
- Zone 3 → "1-point try — must pass."
- Zone 4 → "2-point try — run or pass."
- Zone 5 → "Middle no-run zone. Must pass if ball is spotted here. Also first down line."

If correct: earn a point or bring back one teammate. If incorrect: out.

## See → Decide → Do
- **SEE** — field position; zone landmarks; midfield
- **DECIDE** — fastest path; run or pass allowed?; is this first down territory?
- **DO** — sprint; stop correctly; state rule clearly

## Why This Matters
Players understand scoring structure, conversion structure, first down structure, field segmentation, and when no-run rules activate. You are teaching them how the field works, not just where it is.

# Earlier draft (4-zone version, preserved from the same page)

**Field Awareness, Scoring Structure & Rule Intelligence**

Zones 1–4 as above (no Zone 5). If using a midfield first-down marker, label it separately.

## Why This Game Works
Players develop field orientation, rule clarity under time pressure, conversion awareness, situational scoring understanding, and competitive urgency.
Game transfer: fewer illegal runs in no-run zones; faster extra point alignment; smarter conversion decisions; clearer understanding of scoring structure.

## How to Run the Game

**Phase 1 — Recognition Speed.** Coach calls a zone ("ZONE 3!"). Players sprint immediately and touch the correct line within 5 seconds. Coach counts: "5–4–3–2–1 STOP!" Out if wrong zone, too slow, or not touching the line. Cue: "Sprint first. Think while moving."

**Phase 2 — Add Rule Understanding.** After players arrive, ask "What happens here?" Correct → 1 point, or bring back one teammate (team version). Incorrect → eliminated.

## Team Jailbreak Structure
Split into Red Team / Blue Team. Out if: wrong zone, slow, or incorrect explanation. Bring-back rule: a correct explanation brings back ONE teammate only — do not allow full resets. Game ends when one team is eliminated.

## Proof of Learning
You know it worked when players instantly react to "No-run zone," correct teammates during scrimmage, automatically line up correctly for conversions, and understand when they can run vs. must pass.

## Structured Rounds (to prevent chaos)
- Round 1: Speed only
- Round 2: Add questions
- Round 3: Harder questions
- Final Round: Championship

Sideline players: quick feet, ball security holds. No standing still.

## Extensions
- **Decision Variant:** "You're down 1. Where do you line up?"
- **Strategic Variant:** "You're down 2. What zone do you need?"
- **Directional Variant:** "One-point line LEFT!" — forces scanning and spatial awareness.
