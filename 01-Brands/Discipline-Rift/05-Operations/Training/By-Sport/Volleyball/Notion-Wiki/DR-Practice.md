## Program purpose (Discipline Rift, for ALL sports)
Why we coach: Sport is the vehicle; the outcomes are bigger than the scoreboard.
- Belonging: every child is seen, safe, and has a role.
- Effort Norms: we practice habits — listening fast, trying again, helping teammates.
- Psychological Safety + Productive Struggle: mistakes are expected; we coach the next rep.
- Learning Before Winning: we measure growth through Observable Evidence, not hype.
- Coach as Teacher: coaches create Durable Learning through smart Practice Design and consistent CFU.

### When we teach the "meaning" (so it lands and doesn't steal reps)
Use three short windows (not speeches):
1. Start (20–40s): identity + why today matters
2. 1–2 "Freeze" moments (10–15s each): connect a behavior to a value
3. End (60s): Retrieval Practice + "life lesson" + next step (builds Long-Term Memory)

## North Star: what a "perfect practice" looks like
A perfect practice is Practice with Purpose:
- each block has a Learning Target
- each block uses one Cue (protects Working Memory / reduces Cognitive Load)
- each block includes a Micro-CFU that demands Observable Evidence
- practice moves Simple → Complex Progression toward Transfer
- Time-on-Task stays high (kids are moving, thinking, or helping learning)

## The Repeatable Practice Architecture (7 blocks)

### Block 1 — Culture Routine + Belonging (2–3 min)
Purpose: establish belonging + expectations so you don't "bleed minutes" later.

Coach does (Coach Script):
- name today's Learning Target
- give 1 Cue
- state one Effort Norm (reset speed, listening position, partner respect)

Micro-CFU: "What's the cue today?" (choral response)

### Block 2 — Retrieval Warm-Up (5–7 min) — emphasize the internal analysis
Purpose: prime learning and build memory early through Retrieval Practice (even for beginners: retrieve what you previously taught).

Design: high demonstrations, low talk.
- Beginners: stable reps (low Desired Difficulty)
- Experienced: same task with one added condition (more Desired Difficulty)

Micro-CFU: "Freeze" → coach scans for the cue (observable check)

### Block 3 — Teaching Block (6–8 min)
Purpose: install or re-install the skill/decision with clarity.

Coach does (technical teaching moves):
- show it (brief demo)
- name one Cue
- correct with Specific Feedback that is Actionable and Timely

Practice emphasis: Blocked Practice (stable context to avoid Overloading)

Micro-CFU (10–20s):
- "Show me the cue" (1 rep)
- Exit Criteria: the visible standard for "ready to add complexity"

### Block 4 — Skill Acquisition Reps Engine (10–12 min)
Purpose: volume + confidence + quality reps (where beginners catch up).

Practice emphasis: Blocked Practice → Serial Practice
- start stable (blocked)
- then predictable sequence (serial) that adds one linked action

#### Tier System (solves mixed experience without splitting the group)
Same activity, different demands — athletes move tiers by Observable Evidence:
- Tier 1: stable reps (blocked)
- Tier 3: predictable sequence (serial)
- Tier 5: same skill under a simple constraint (more Desired Difficulty)

Micro-CFU: "Name the cue + show one rep."

### Block 5 — Teaching Acquisition (guided learning under decisions) (10–12 min)
Purpose: connect technique to Decision-Making using See → Decide → Act.
This is where you train Perception, Perceptual Cues, Decision Speed, and Decision Quality.

Design principles:
- Representative Practice: looks like the game without full chaos
- Desired Difficulty: add one variable (space / time / pressure), not three at once

Practice emphasis: Interleaving + light Randomized Practice
- mix two related skills/decisions
- vary the situation so kids must read and choose

Fast teaching moves (keep reps flowing):
- Perception Question ("What did you notice?")
- Freeze (rare)
- Recreate the Situation
- Replay immediately

Micro-CFU: athlete answers a perception question *and points to evidence* (stops the Assumption Trap)

### Block 6 — Application (Constraint Game) (10–15 min)
Purpose: build Transfer (learning holds up under real conditions).
This is not a free play scrimmage — it's a Constraint Game with Metrics That Matter.

Practice emphasis: Randomized Practice + Interleaving
- unpredictable decisions
- multiple skills appear naturally

Coach focus: reinforce the learning target, not the outcome.
- track decision success ("right choice") and process success ("used the cue")

Micro-CFU between rounds: "See → Decide → Act" in one sentence.

### Block 7 — Debrief + Exit Criteria + Spacing (2–3 min)
Purpose: turn today into long-term learning.

Coach does:
- 1 quick DR meaning tie ("How did we show discipline / teamwork / courage today?")
- 1 Retrieval Practice question (from memory)
- name the next Spaced Practice revisit ("We'll touch this again next week during warm-up.")

Exit Criteria: what "learned" looks like (observable, simple)

## How the practice methods intertwine (curriculum explanation)
Use this exact paragraph in your curriculum:
- Blocked Practice builds clarity and confidence while protecting Working Memory and reducing Cognitive Load — especially for beginners.
- Serial Practice adds a predictable next step so athletes progress Simple → Complex Progression without losing the cue.
- Interleaving and Randomized Practice are where real Decision-Making develops because athletes must use Perception and execute See → Decide → Act in changing situations.
- Retrieval Practice prevents the "I taught it vs they learned it" problem by requiring athletes to recall learning from memory.
- Spaced Practice (part of Season Design) makes learning durable by revisiting targets over time so athletes can retrieve and perform later under pressure.

## "Maximize every minute" operating rules (coach standards)
- One Learning Target per block.
- One Cue per block (avoid Overloading).
- Micro-CFU every 3–5 minutes using Observable Evidence.
- Only 1–2 total Freeze moments per practice; always Replay after correction.
- Protect Time-on-Task: transitions are taught like skills.
- After practice: one 1% Solution (tiny fix) to improve next time (Marginal Gains).
