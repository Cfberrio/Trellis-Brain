## Purpose
Strategic source-of-truth for how DR converts leads into enrolled families. Operational details live in [[01-Brands/Discipline-Rift/01-Systems/Sales/Sales-Process|Sales Process]].

## Entry Point
1. Parent receives flyer → scans QR
2. Lands on site → pop-up offers Parent Guide
3. Parent submits **name + email** (recommended: phone + child age/grade + school + sport interest, to qualify + segment)

**Why add qualifying fields?** Hormozi's lead nurture process starts with: look at best customers → ask those questions → score leads → route best leads to best closers, then segment messaging.

## Conversion Path
```
opt-in (Parent Guide) → immediate response → 7-day conversion sprint → enrollment checkout (self-serve)
                                                                       OR short closer assist → onboarding
```

**Core principle:** speed-to-contact + number of follow-ups + responses are direct drivers of show rate (people actually taking the next step).

## Nurture System

### 7-Email Welcome Series

| # | Theme | Purpose |
|---|---|---|
| 0 | Guide delivery + "what happens next" | Deliver promised asset, one clear CTA |
| 1 | Logistics friction | Address Segment 2 (logistics-overwhelmed) |
| 2 | Beginner-friendly / safe-to-learn | Address Segment 1 (anxious beginner) |
| 3 | Trust — coach quality + safety | Proof clip or testimonial |
| 4 | Cost & commitment clarity | Address Segment 3 (price-sensitive) — "season = predictable" |
| 5 | Proof drop | Screenshots, testimonials, video-in-email |
| 6 | Decision email | "Spots close / season starts / enroll now" |

> Each email contains exactly **1 CTA** with full "what to do next / when / what they get / what happens next" structure.

### Cadence (Hormozi-aligned, first 30 days)
- **Day 0:** immediate email + (if phone collected) call/text fast
- **Days 1–2:** 2 touches/day
- **Days 3–7:** 1 touch/day
- **Days 8–30:** weekly touches (proof + reminders)
- **After Day 7 / first 7-day sprint over:** lighter weekly nurture through Day 30 or until they convert
- **After Day 30:** treat quarterly emails as "reactivation + proof + CTA", not core conversion engine

### What This Improves
- **Response rate:** more touches + clearer CTAs → more replies/clicks
- **Show/enroll rate:** fewer days out + faster contact + more follow-ups
- **Close rate:** segmenting + routing best leads to best closers

## Sales System

### Qualification (before spending time closing)

**YES (qualified):**
- Child age 6–12
- Attends served school
- Parent can pay per season (or accepts split-pay)
- Wants fun-first / on-campus convenience (not elite travel-club)

**NO (unqualified):**
- Out of age range or school not served
- Wants elite-only competitive structure DR doesn't offer
- Cannot attend after-school window at all

**Lead scoring:** 1–5 or red/yellow/green. Route **green** to human assist if they don't buy quickly.

### Sales Modes

**Mode A — Checkout Close (no call):** Every email ends with one CTA + "what happens next". If they click but don't buy → trigger "main concern" email.

**Mode B — Closer Assist (5–10 min):** Closing's core — give them power to decide by (1) understanding what they want, (2) putting that next to the options, (3) making sure they reach a genuine decision.

### Mode B Call Skeleton
1. Confirm basics (age / school / sport)
2. Ask: what do they want for their kid? (fun, friends, confidence, activity)
3. Ask: what's stopping them from enrolling today?
4. If they stall: ask for **main concern** — don't let "maybe" linger
5. Handle the concern → ask for decision → enroll

**Follow-up rule:** No limbo. If not now, set the next decision point or disqualify.

## Objection Handling Map (Top 5)

Hormozi buckets objections as "blame" types: circumstances/time/money/fit (Circumstance), other people/trust (Other-People), self/fear/avoidance (Self).

### 1. "Will my kid like it or quit?"
**Response:** "What's your main concern about them trying it?" (force the real issue)
**Then use risk-reversal:** they can't know until they try. If you have a guarantee/trial → use "try it risk free" logic.

### 2. "Is it safe / is this for beginners? I don't want embarrassment."
**Response:** Treat as fear/self-blame. Return decision power: identify what "unsafe" means to them, then map to "safe-to-learn" structure. Same "main concern" first.

### 3. "We're busy / we'll miss practices."
**Response:** Classify as time (circumstance blame). Confirm what would need to be true for yes, then present the simplest path (on-campus convenience, predictable season).

### 4. "It's too expensive."
**Response:** Don't haggle. Use: **"If this were free, would you do it?"**
- YES → it's not money; handle the real concern
- NO → disqualify (not a fit) or downsell

> "It's Not, Not The Money" — Closing playbook explicit.

### 5. "I need to check with my spouse."
**Response:** Prevent via qualification — decision-makers on the call before investing time. Reschedule if not.
If you must handle it live, ask: "What if they say no?" → route to what they'd object to → close the gap.
