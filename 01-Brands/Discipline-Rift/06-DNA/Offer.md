## Offer Name
**Discipline Rift On-Campus Sports Season** *(sport swap per school: volleyball / flag football / tennis / pickleball)*

## Promise (measurable + auditable)
In one 6-week season, your child will:
1. **Attend X coached practices** (X = set number of sessions for the season)
2. **Participate in guided gameplay** (scrimmages / game-based reps built into sessions)
3. **Be assessed using our sport-specific Tier System** and receive:
   - A starting **Tier placement** (baseline)
   - An end-of-season **Tier achievement** (highest Tier demonstrated)
4. **Parents receive 1 weekly update** on a fixed day (e.g., every Friday) confirming: attendance + Tier skills trained + what's next.

**Why measurable:** attendance, gameplay inclusion, Tier placement, Tier achievement, and weekly updates are all trackable (yes/no).

> If you want to include "confidence/friends," keep it as a *supported outcome* (what it leads to), not the measurable promise — unless you add a simple rubric you actually score.

## Mechanism (the vehicle)
A fun-first, beginner-friendly on-campus after-school season led by trained coaches using a **Tiered progression** (skills ladder) that takes kids from "new" → "competent" through consistent structure, game-based reps, and safe-to-learn coaching.

## The 3 Deliverables (Trim — what actually sells)
Everything in delivery supports these three. No extras unless they strengthen one of these.

### Deliverable 1 — On-campus convenience
- After school, on campus, clean dismissal/pickup handoff
- Predictable schedule + clear start/end (season container)

### Deliverable 2 — Beginner-friendly, safe-to-learn structure
- No experience needed
- Built-in confidence ramp (teach → rep → game)
- Clear rules for psychological safety (no pressure / no embarrassment)

### Deliverable 3 — Trained coaches + clear season structure
- Consistent coaching standards
- Same session format each week
- Tier System progression (skills ladder) + end-of-season achievement

> Everything else (gear included, reminders, "what to expect") becomes **supporting proof** for these three, not new "pillars."

## Offer Construction (obstacles → solution → delivery)

Instead of 7 separate pillars, route obstacles into the 3 deliverables.

### Obstacle: "We don't have time / logistics are hard"
- **Solution:** remove friction
- **Delivered via:** On-campus convenience + predictable routine + clean dismissal flow

### Obstacle: "My kid is nervous / will be embarrassed / might quit"
- **Solution:** safe-to-learn, beginner-first
- **Delivered via:** Beginner-friendly structure + games-forward reps + clear expectations

### Obstacle: "Can I trust this? Is it worth it?"
- **Solution:** certainty + structure + visible progress
- **Delivered via:** Trained coaches + Tier System + weekly update cadence + consistent format

## Tier System (measurement system, not flavor text)

Present as the **measurement system**.

**Tier System promise (generic across sports):**
- Each sport has **Tier 1 – Tier N** with defined skill outcomes.
- Coaches teach toward these outcomes during the season.
- Kids receive **Tier placement at start** + **Tier achievement at end** (certificate/badge).

**Operational fix:**
- Each Tier's outcomes must be **non-overlapping** and written as **observable behaviors** (avoid repeats like "ready position" appearing twice).
- Keep **4–6 outcomes per Tier** max so it's teachable and scorable.

## Proof Assets (Likelihood Engine)
Map proof directly to the 3 deliverables:
- **On-campus convenience:** pickup flow clarity + parent quote about "no driving"
- **Beginner-friendly:** shy/beginner testimonials + "first day nervous → later smiling" clips
- **Coaches + Tier System:** coach credential snippet + Tier certificate example + baseline/end snapshots

## Guarantee (choose one)

### Option A (recommended) — Fit Guarantee (simple, conditional, credit-based)
> "If after the first 2 practices you don't feel it's a fit, email us within 48 hours after practice #2 and we'll issue a full credit toward another sport season (or the next season)."

- Conditional (limits abuse)
- Credit (protects cash)
- Time-bound (prevents end-of-season refunds)

### Option B — Remove until finalized
If not ready to honor and administer cleanly → **don't mention a guarantee yet**.

## Supported Outcomes (optional — only if measured)
If you want to claim sportsmanship / respect / discipline → either measure it OR position as byproduct.

**Measured version:**
- Coaches score 1–5 weekly on: effort, sportsmanship, teamwork (internal)
- End-of-season "character note" (optional — not a certificate if not awarded)
