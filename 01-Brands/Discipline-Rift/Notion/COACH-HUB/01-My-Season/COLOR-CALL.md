# RETURN + PROBLEM: RETURN IS A GUESS → COLOR CALL
**Setup:** Server and returner in standard positions, server at or inside the service line for early success. A different-colored spot/zone marked in each half of the returner's target area.
**Show It:** Demonstrate the server tossing/serving into play, then calling out which colored zone the returner must send the return toward.
**Challenge:** Server serves and calls a zone color. Returner must return the ball toward that specific zone — not just anywhere.
**Progress/Win:** Land the return in the called zone 4 of 5 attempts = ready to call the zone after the toss instead of before (harder read).

**Coach Watches For:** Split step before the return, a real plan (the called zone) rather than a reflex swing.
