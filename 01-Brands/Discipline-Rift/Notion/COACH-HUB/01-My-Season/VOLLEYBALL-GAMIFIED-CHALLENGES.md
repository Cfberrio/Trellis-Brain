# VOLLEYBALL GAMIFIED CHALLENGES
Every challenge follows the same shape: **Skill + Problem + Gamified Challenge**. Each page tells you the setup, how to run it, how a player wins, how to make it easier or harder, what to watch, and when the group is ready for the next problem.
<callout icon="💡" color="gray_bg">
	**HOW TO PICK ONE**
	Run two or three short challenges in the 30 minute Progression Ladder block. Do not try to run the whole bank.
	Start from the problem you can see today, not from the week number. Two groups on the same court can be on different challenges.
	A Golden Ticket unlocks **one** new demand: a new distance, entry, role, or target. It is never permanent status and it never controls who gets the ball.
</callout>
