# WEEK 6 - PLAY ACTION

**Theme:** *Strategy Makes Us Hard to Guard*
**DR Focus:** one main cue, high reps, fast resets, no sitting (JOB ZONE)
**Cue of the Week (ONE cue only):** **“SELL THE FAKE.”**
### What “SELL THE FAKE” means (kid version)
- RB takes the fake like it’s real: **eyes upfield + run steps** (don’t stop)
- QB acts like it’s a real run first, then passes (we *don’t* coach QB today—just mention)
**Coach words (every rep):**
👉 “FAKE IS REAL… SELL IT!”
**Observable proof**
- RB takes **2–3 real run steps** after the fake (not a jog, not standing)
- RB doesn’t turn into a receiver too early
- Fake looks the same speed as a real handoff start
---
## Same every week — “OUT” = JOB ZONE (no sitting)
Set two cones on the sideline.
### Quick Job (10 seconds)
- **Instant Coach (primary):** tell next player the cue + quick demo
	👉 “SELL THE FAKE!” (show 2 run steps)
- **Skill Sprint (backup):** 3 squeezes + 2 switches + 1 freeze “safe window”
Re-entry: back in on the next reset/whistle.
---
# DR PRACTICE SPINE (60 minutes)
## Block 1 (3 min) — Belonging + Routine
**Script (tight):**
“Team in. Sport is the vehicle. Today we’re leveling up **offensive strategy**.
Our ONE cue: **SELL THE FAKE.**
If you’re out, you’re on a job—quick job, back in fast.”
**Micro-CFU:** “What’s the cue?” → “SELL THE FAKE!”
---
## Block 2 (8 min) — Retrieval Warm-up (last week’s cue + movement)
### **Strategic Flag Tag 4v4** (curriculum “instant activity”)
**Setup**
- 4 cones make a small field/grid
- 4v4: 2 offense / 2 defense on each side if you want more reps, or true 4v4
- Everyone wears flags
**How to play (as written, simplified)**
- Offense tries to reach opposite goal line without getting flags pulled
- If a flag is pulled: offensive player returns to their side, puts flag back on, tries again
**Retrieval cue (from Week 5):** *“Elbow up pocket”* (say once only during first minute)
**JOB ZONE:** if your flag is pulled → quick job → back in
---
## Block 3 (7 min) — Skill Clarity (new cue)
### **Play Action Pass — 20–30s clarity demo**
Curriculum defines Play Action as: QB fakes handoff to RB, **RB goes out for a pass**.
**Teach the sequence (super short):**
1. QB and RB start like it’s a run
2. **RB sells the fake** (2–3 run steps)
3. RB “leaks” out as receiver
4. QB throws
**ONE cue only (RB):**
👉 “SELL THE FAKE.”
**CFU (5 seconds):**
“Freeze—show me 2 run steps after the fake.” (Everyone demos in place.)
---
## Block 4 (12 min) — Fluency Reps (high reps, low talk)
### **Play Action “On Air” Reps (no defender)**
(Aligns with “practice executing play action skills… switch roles… multiple roles.”)
**Setup (groups of 4):** QB / RB / WR / Center
- Optional: skip the snap and start with “Set-Hut” to reduce fumbles (curriculum suggests this option in small-group play).
**Rep pattern (rotate every 2 plays)**
- Play 1: Fake → RB leaks → short throw to RB
- Play 2: Fake → RB leaks → short throw to WR
	(Keep throws easy. Success \> difficulty.)
**Rep goal**
- 8 play-action reps per group (fast)
**Coach says only**
👉 “SELL THE FAKE!” (reward the 2–3 real steps)
**Common errors + fixes**
- RB turns too early → “Two run steps first.”
- Fake looks slow → “Fake is REAL speed.”
- QB rushes throw → “Hold one heartbeat” (say once, then back to RB cue)
---
## Block 5 (13 min) — Decision Reps (add read/time/defender)
### **Play Action Pass — Add a “Guide Defender”**
(Still coached by the same cue; now with pressure.)
**Setup**
- Same groups of 4
- Add **one defender** whose ONLY job is to watch RB at walk pace
- Defender can’t rush QB; just “reads” RB
**Rule**
- If RB doesn’t sell it (no real steps), defender calls “READ!” and that rep doesn’t count.
- If RB sells it, defender has to hesitate 1 beat before covering.
**Score (per group)**
- 1 point: completed pass
- +1 bonus: coach sees **clear sell** (2–3 real steps)
**JOB ZONE** for drops / wrong route / offside: instant coach “SELL THE FAKE” → back in.
---
## Block 6 (14 min) — Application / Constraint Game
### **4th Down (Offense Only)** (curriculum “key activity”)
Goal: group of 4 works together to score on each “4th down.”
**Setup**
- Fields/grids: **20–25 yards** each (as written)
- Groups of 4 rotate QB/WR/RB/Center
**How to run (simple)**
- Each QB chooses & calls one play; run 4 plays total, then rotate QB (matches curriculum).
- Require teams to include:
	- 1 run
	- 1 pass
	- 1 play action
	- 1 “best play” (their choice)
**Scoring that rewards the cue**
- 2 points = TD
- +1 bonus = **Play Action TD where RB sold the fake**
- +1 bonus = team rotates positions cleanly (no arguing; quick reset)
**Feedback layer (peer learning)**
Curriculum notes feedback is critical because students are helping each other learn roles.
So: after each play, one teammate gives **one “Glow”**:
- “I saw you sell it with 2 steps.”
---
## Block 7 (3 min) — Wrap + Exit Ticket
**Exit ticket (matches curriculum CFU idea)**
- “Tell your partner the sequence of play action.”
- “Why do we sell the fake?”
**Shout-out tied to the cue**
“I saw ___ sell the fake with real run steps—that’s what made the pass open.”
---
# Week 6 Gamefication: **“Offensive Coordinator Challenge”**
A team earns the **Coordinator Patch** if they:
1. Run **1 run + 1 pass + 1 play action** during 4th Down
2. Rotate roles fairly
3. Coach hears **3 loud cue calls** from teammates: “SELL THE FAKE!”
	(Quick tally on clipboard.)
