# SERVE → READ → CATCH
<callout icon="🏐" color="gray_bg">
	**SETUP**
	Trios: server on one side, receiver and target on the other. One ball per lane and clear collection routes. Server uses an appropriate short distance.
</callout>
## Demonstrate and play
1. Server names a broad reachable area and serves.
2. Receiver tracks the serve, catches it, then tosses to the target.
3. Rotate server → receiver → target after three starts. Walk around the net end only when play has stopped.
4. Next version: the receiver passes and the target catches.
## How to progress and win
One team point for a legal practice start followed by a controlled reception and connection. The goal is five shared starts, not aces against a beginner.
**Golden Ticket:** three read-and-catch successes unlock pass-to-target receiving.
## Adjust the challenge
<table header-row="true">
<tr>
<td>Make it easier</td>
<td>Make it harder</td>
</tr>
<tr>
<td>Start with an over-net toss. Let the receiver start closer to the likely landing area.</td>
<td>Replace the receiver's catch with a forearm pass. Later add a second receiver so they must decide whose ball it is.</td>
</tr>
</table>
<callout icon="💡" color="gray_bg">
	**COACH WATCHES FOR**
	Cue: **"Watch it leave the hand."** Tell the difference between a poor feed and a receiving error.
	**If it breaks:** every serve missing the receiver's area → practise serving briefly and run CFU from a toss start.
</callout>
## Ready for the next problem when
The receiver adjusts to more than one serve location and sends a playable ball onward.
