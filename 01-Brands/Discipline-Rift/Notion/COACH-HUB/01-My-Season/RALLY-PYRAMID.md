# BACKHAND + PROBLEM: RALLY DIES, NO VISIBLE PROGRESS → RALLY PYRAMID
**Setup:** Pairs, one ball, four balls set aside to build a pyramid (three in a triangle, one on top).
**Show It:** Player 1 tosses to Player 2, who returns it with a backhand; Player 1 sends it back. Every completed exchange adds a ball to the pyramid.
**Challenge:** Build the whole pyramid before the rally breaks down. If it drops, start the pyramid over.
**Progress/Win:** Complete pyramid = switch sides of the court and rebuild farther back.
