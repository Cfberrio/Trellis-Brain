# SERVE + PROBLEM: TARGET SERVING TOO HARD, NO VISIBLE PROGRESS → SERVE PYRAMID
**Setup:** Pairs — one server, one returner-catcher — four balls set aside to build a pyramid.
**Show It:** Server throws (or serves) diagonally into the box; returner catches it and tosses it back. Every successful serve-and-catch adds a ball to the pyramid.
**Challenge:** Build the pyramid before switching roles. Complete the rotation, then switch sides of the court.
**Progress/Win:** Progress from an underhand throw, to an abbreviated overhand serve, to a full serve as the pyramid consistently completes.
