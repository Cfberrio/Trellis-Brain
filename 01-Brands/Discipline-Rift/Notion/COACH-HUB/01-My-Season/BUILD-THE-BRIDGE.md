# BUILD THE BRIDGE
<callout icon="🏐" color="gray_bg">
	**SETUP**
	Groups of four: tosser, passer, setter, catcher. One ball, one setter area, one final target.
	With ten players use two groups of five. The fifth resets balls and enters on every new sequence.
</callout>
## Demonstrate and play
1. Toss → pass toward the setter → set toward the catcher → catch.
2. When the ball ends, everyone advances one role. The catcher returns the ball to the next tosser.
3. If the connection breaks, identify the **earliest** unplayable contact.
4. Give one cue and replay from the same entry before rotating.
## How to progress and win
One bridge section per completed sequence. Build three sections across attempts. If connections rarely finish, temporarily score the playable first pass on its own.
**Golden Ticket:** three sections unlock a new entry angle or the final sender role. Demonstrate the new skill before you require it.
## Adjust the challenge
<table header-row="true">

<td>Make it easier</td>
<td>Make it harder</td>
</tr>

<td>Let the setter catch and self-toss before setting, or replace the set with a toss while passing is the only new skill.</td>
<td>Remove the catch support, vary the first feed, then replace the final catch with a controlled send.</td>
</tr>

<callout icon="💡" color="gray_bg">
	**COACH WATCHES FOR**
	Height and destination of the first pass. Cue: **"Help the next player."** Feedback stays on the selected skill even if a later contact fails.
	**If it breaks:** setter constantly chasing → fix first-contact direction or enlarge the setter area before you change setting technique.
</callout>
## Ready for the next problem when
The group connects from more than one feed location. Test it in CFU with opponents and no fixed first receiver.
