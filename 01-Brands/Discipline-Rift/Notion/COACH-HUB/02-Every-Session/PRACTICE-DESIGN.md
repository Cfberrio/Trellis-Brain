# PRACTICE DESIGN
<callout icon="🧠" color="gray_bg">
	**Practice Design = the shape of practice.**
	**Progression Ladder = the developmental path inside it.**
	**Coach Rules = how you coach each rep.**
</callout>
<callout icon="💡" color="gray_bg">
	**Practice Design** is the whole concept: how a practice is organized, sequenced, coached and checked from start to finish. There is no separate Practice Structure page and no separate Practice Template. This is it.
</callout>

## THE DR PRACTICE
**OPEN → RETRIEVE / SHOW → BUILD THE LADDER → TEST TRANSFER → CLOSE**
### 1 · Open
Get the group organized, say the learning goal out loud, get players moving fast. Keep setup talk short.
- Attendance and equipment ready.
- Say what players are learning today.
- If movement preparation is needed, connect it directly to the first task. It is not a separate curriculum block.
### 2 · Retrieve / Show
<callout icon="1️⃣" color="gray_bg">
	**WEEK 1 — SHOW THE SPORT**
	Demonstrate what good play can eventually look like. Then narrow the focus: "This is where we are going. Today we start here."
</callout>
<callout icon="🔁" color="gray_bg">
	**WEEKS 2–6 — RETRIEVE FIRST**
	Give players a quick chance to show what survived the week away. Use that evidence to choose the starting rung.
</callout>
### 3 · Build the Progression Ladder
This is the main body of practice. Every rung answers three questions:
**SKILL + PROBLEM + GAMIFIED CHALLENGE**
Inside a rung: **show it → run it → coach it → vary it → check it.** Success creates the next problem, which creates the next rung.
<callout icon="🪜" color="yellow_bg">
	**THE LADDER ON EVERY WEEK PAGE IS A SAMPLE.** Every team is different. Start where your players can succeed.
	[[PROGRESSION LADDER]]
	*The sample ladder. Name it, show it, challenge it, coach reps, vary, check.*
</callout>
<callout icon="💡" color="gray_bg">
	The ladder is not "Passing Week, Serving Week, Attacking Week." A skill can return many times under new conditions. That is how practice becomes serial and how retrieval happens.
</callout>
### 4 · Test transfer
Use a sport-specific **CFU Game**. Change the situation enough that players have to retrieve and adapt: space, target, role, pressure, direction, scoring, communication, number of touches, or entry.
If learning breaks: **Freeze → Cue → Replay.** Keep the intervention short, then let them try again.
### 5 · Close
- Ask for or observe one piece of learning.
- Recognize a specific behavior or improvement.
- Preview what the next problem may be.
No required life-lesson block. Keep the close useful and brief.
## HOW THE PRACTICE SHOULD FEEL
<table header-row="true">
<tr>
<td>Standard</td>
<td>What it means</td>
</tr>
<tr>
<td>High reps</td>
<td>3 lines per coach whenever roster and space allow. Minimal waiting.</td>
</tr>
<tr>
<td>Visible teaching</td>
<td>Players see the movement. Coaches narrate the demonstration instead of giving a long explanation first.</td>
</tr>
<tr>
<td>Constant coaching</td>
<td>Feedback happens while reps are happening. Praise and correction both point players toward the next rep.</td>
</tr>
<tr>
<td>Simple → complex</td>
<td>Start clear. Add variation only after players begin succeeding. Difficulty follows learning.</td>
</tr>
<tr>
<td>Multiple exposures</td>
<td>Important skills return at different moments rather than being finished in one block.</td>
</tr>
<tr>
<td>Observable learning</td>
<td>Do not ask only "Got it?" Look for what players can actually do when conditions change.</td>
</tr>
</table>
## WHAT PRACTICE DESIGN IS NOT
- Not a fixed seven-block clock.
- Not a separate "Practice Structure" plus "Practice Template."
- Not one skill taught once and then left behind.
- Not a drill list.
- Not a scrimmage with no learning target.
