# INCIDENTS
## BEHAVIOR: THE 3 CALL-OUT RULE
This is DR's existing escalation rule, moved here from the tennis Week 1 plan where only tennis coaches could find it.
1. First Callout: Coaches will speak to the player.
2. Second Callout: Player will be placed in timeout during class.
3. Third Callout: Parent talk.
The parent talk routes through DR, not the coach: DR notifies the parents. One documented case removed a child from a roster with the parents never warned first. The parent talk exists so that never repeats.
