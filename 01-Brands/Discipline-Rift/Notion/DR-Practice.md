# DR Practice — Universal Practice Structure (DR-UPS)

> Sport = vehicle. Outcomes bigger than scoreboard. Belonging · Effort Norms · Psychological Safety + Productive Struggle · Learning Before Winning · Coach as Teacher.

Sister page → [[Why-DR-Practice]]

## Meaning windows (no speeches)
1. **Start (20–40s)** — identity + why today matters
2. **1–2 Freeze moments (10–15s)** — connect behavior to value
3. **End (60s)** — Retrieval Practice + life lesson + next step

## North Star — Practice with Purpose
Each block has:
- one **Learning Target**
- one **Cue** (protect Working Memory, reduce Cognitive Load)
- a **Micro-CFU** demanding **Observable Evidence**
- Simple → Complex Progression toward **Transfer**
- High **Time-on-Task**

## 7-Block Architecture

| # | Block | Time | Practice Mode | Purpose |
|---|-------|------|---------------|---------|
| 1 | Culture Routine + Belonging | 2–3 min | — | Establish belonging + expectations |
| 2 | Retrieval Warm-Up | 5–7 min | Retrieval | Prime memory, low talk |
| 3 | Teaching Block | 6–8 min | Blocked | Install skill, one cue |
| 4 | Skill Acquisition Reps Engine | 10–12 min | Blocked → Serial | Volume + confidence (Tier 1/3/5) |
| 5 | Teaching Acquisition (Guided Decisions) | 10–12 min | Interleaving + light Randomized | Train See → Decide → Act |
| 6 | Application (Constraint Game) | 10–15 min | Randomized + Interleaving | Build Transfer under pressure |
| 7 | Debrief + Exit Criteria + Spacing | 2–3 min | Retrieval + Spaced | Convert to long-term learning |

## Tier System (mixed experience, no group split)
- **Tier 1** — stable reps (blocked)
- **Tier 3** — predictable sequence (serial)
- **Tier 5** — same skill + simple constraint (more Desired Difficulty)
Athletes move tiers via Observable Evidence.

## Method intertwine (curriculum paragraph)
- **Blocked** → clarity, confidence, low Cognitive Load (beginners)
- **Serial** → predictable next step, Simple → Complex Progression
- **Interleaving + Randomized** → Decision-Making, Perception, See → Decide → Act
- **Retrieval** → solves "I taught it vs they learned it"
- **Spaced** (Season Design) → durability under pressure

## Coach standards — Maximize every minute
- 1 Learning Target per block
- 1 Cue per block (no Overloading)
- Micro-CFU every 3–5 min via Observable Evidence
- Max 1–2 Freeze moments per practice; always Replay
- Transitions taught like skills
- Post-practice **1% Solution** (Marginal Gains)
